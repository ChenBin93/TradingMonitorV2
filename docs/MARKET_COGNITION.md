## 二、对市场的认知：四层模型

### 第 1 层：方向层 = 近似有效市场

- 运行肥尾不存在（加密 + 现代传统市场；仅书时代利率有）
- 自相关 lag≥2 近零（"近零持久边界"=2 根 bar，c38）
- 反持久真实但弱（run 比硬币短 z=−9.45，但 1:1 过不了成本关）
- 1:1 方向赌注全家族无优势（触碰/突破/RSI/背离/状态方向/择时——c21/c23/c25/c40/c48/c51/c54/c55）
- 趋势系统 5/6 弱正（c47）——是**漂移捕获**，不是 alpha
- 方向=拥挤度，不是趋势质量（c27/c29：高 ER 触碰折返更深）
- **结论：方向层只有 beta（漂移）没有 alpha；"猜方向"在数学上等于抛硬币**

### 第 2 层：波动层 = 强可预测，但已被定价

- 波动长记忆 H≈0.9（c12）
- **三重释放信号**：关键位触碰 +7.4pp（c15）→ 高 ER 触碰 +16.3pp（c27）→ 2σ 带触碰 +15.9pp@z≈17σ（c51），释放形态"即启、持续、缓饱和"（c52）
- 量是波动的镜像：跟踪（ρ=0.53~0.68）+ 领先 + 长记忆（c49）
- **但期权已定价**：触碰时 IV 隐含 breakeven 21.1% vs 实际释放 8.6%（c57）——买侧连续负（c57 事后 −4.2%、c59 事前 −2.3%），卖侧系统性正（c58 +4.2%，尾部比随机温和）
- **结论：波动可预测是真的、强的、量级最大的市场结构——但"可预测"本身被市场定价。预测的价值在风险管理（警报器）和卖侧（IV 高估），不在买侧**

### 第 3 层：结构层 = 市场指纹（描述真实、方向可收割性 null）

- 关键位=围墙：价格绕行不穿透（c14）——**波动描述层真实，方向概率层 null**（两套"位"的 1:1 都 ≈ 抛硬币，c51）
- 区间留存高（c16）、触位折返倾向真实（c17）——描述真实、强度不够
- 美股时段量能驼峰（14:00 UTC 峰 1.83，c49）——与 live 推送窗口暗合
- 加密截面 n_eff=2.15（c37）：20 个币 ≈ 2 个独立信息源——加密"分散化"的真实边际
- 时代效应：书时代肥尾衰减（c42）——市场会变老
- funding=拥挤度定价：数据不足，无证据（c49）

### 第 4 层：成本层 = 加密的生死线

- taker 成本吃小 edge（c21/c23/c25 全系列 + c26"成本亏损"）
- 成本侧本身是 alpha 的载体：**同一套信号，taker 付 0.05%、maker 收返佣+价差——每笔翻转 ~0.07%+，年化累积足以把弱正放大成显著**（maker 线未测，缺 tick 数据）
- 摩擦的另一半：funding（持仓时间成正比，与"低频降摩擦"反向）

## 三、统一模型（一句话版）

> **加密永续 = 方向近似有效 + 漂移（beta）+ 波动强可预测但被期权定价 + 结构描述真实但方向可收割性 null + 成本决定一切。**
>
> **我们能预测"何时炸"（z≈17σ），不能预测"往哪炸"（全 null）——市场的记忆在波动上，不在方向上；钱在波动侧和成本侧，不在方向侧。**

三层判卷规则（贯穿 33 项考证的方法论）：

1. **描述层**（市场"是什么形状"）：真实——关键位、波动释放、量能时段、肥尾时代性
2. **可收割层**（"能不能从形状里赚钱"）：null——一切方向赌注、一切波动买入
3. **定价层**（"市场自己知不知道"）：有效——期权把波动信号吃干净

## 四、实践含义

1. **风险警报器**（立刻可用）：2σ 带触碰/关键位触碰 = "波动要炸"预警 → 减仓/收止损。这是 33 项考证里量级最大、可直接落地的产出
2. **卖波动线索**（c58 +4.2%，n=84 需扩数据）：触碰时 IV 系统性高估的收割
3. **maker 线**（未测，需 tick 数据）：成本侧 alpha 的正面
4. **beta 长期持有**：漂移为正（c18），但那是 beta 不是 alpha，且永续有 funding 拖累
5. **live 系统定位转变**：从"找入场信号"→"风险事件预警 + 波动状态监控"——研究证明前者无解，后者有 z≈17σ 的可靠信号

## 五、与书的关系（最后一句话）

> Kaufman 给了我们一套精确的度量学工具箱（公式、定义、机制全部逐位成立）和一张时代的经验地图；我们用这套工具箱重新测量了自己的市场，发现：**书的工具全对，书的赚钱断言在本市场过期，市场的钱在波动侧和成本侧，不在方向侧。** 而"发现钱不在哪里"这件事本身，价值不亚于"发现钱在哪里"——因为书里教的每一个方法，直接上手就是 c40/c48/c54 里量化的亏损。
