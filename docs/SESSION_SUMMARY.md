## 二、核心验证结论（全部 416 天数据）

### 1. 日线趋势是唯一方向源（主线论）
- 日线顺势优势：做多 +5.6pp，做空 +12.5pp
- 4H/1H 逆向只是短暂插曲（1H 状态平均只活 6 小时）
- **顺大逆小**：日线顺势 + 4H/1H 回调入场 = 60-67%
- **插曲起点是黄金点**：日线顺势 + 4H 刚翻逆向（回调初期）= 61-64%

### 2. 周期跨度传导
- 4-6x 跨度：传导 22-24%（黄金匹配）
- 12x：16.1%，24x：12%，48x：6.9%，288x：2.4%
- 5M 是通道内噪声（1H 通道方向不预测 5M 单根方向）
- 1H 是趋势效应甜点层

### 3. RS 的位置依赖（最新发现）
- **做空**：日线空 + RS<-60（极端弱势币）→ 58.3%（+1.9pp）
- **做多**：日线多 + 4H回调 + RS强 → 57.1%（回调中强势=抗跌）
- **过冲**：全顺势 + RS强 → 52.8%（追高危险）
- RS 符号测试（>0/<0）无效，必须用极端绝对值（±60）
- RS 本身不预测未来收益（纯 RS 分档无区分度）

### 4. 结构（S/R）
- 结构**无方向倾向**（支撑做多不比阻力做多准）
- 结构**强度有效**（touch≥3 比 2 触 +1.1~1.6pp）
- 结构是信号锚点（retest/breakout 靠它盈利），不是方向预测器
- 最佳组合：日线顺势 + 贴强 S/R（做空 57.3-58.0%）

### 5. 趋势定义
- 三种定义等价：MA排列 / 价+MA20斜率 / 纯价vsMA20
- 纯价vsMA20 最简单且覆盖最全（无中性态）
- **live 尚未简化**（用户说"先不改"）

### 6. 其他
- 信号本身无 edge（1:1 = 50%，数学本质：单根 K 线无条件对称）
- 未来函数修复（K线时间戳=开盘时间）是分水岭
- fakeout/long 45.1% 毒药、1H空+做多 46.1% 毒药
- ADX 无方向 edge、位置过滤无区分度
