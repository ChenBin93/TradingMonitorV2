# 入场优化模型 — 挂单价与 EV 最优化

> 核心问题：限价单挂在哪，期望收益最大？

---

## 一、模型设定

### 已知量（系统提供）

| 符号 | 含义 | 来源 |
|------|------|------|
| P_def | 防线价格 | support_resistance |
| P_opp | 对侧防线价格 | support_resistance |
| P_now | 当前价格 | 15m close |
| ATR | 波动率 | indicators |
| N | 防线触及次数 | support_resistance |
| W(N) | 防线上的胜率 | N=3→65%, N=2→50% |

### 决策变量

- **P_entry**：挂单价（P_def ≤ P_entry ≤ P_now，对多头）

### 子函数

```
RR(P_entry) = (P_opp − P_entry) / (P_entry − SL)
           其中 SL = P_def − 0.3·ATR

成交率(P_entry) = P(价格先碰到 P_entry 而非 P_opp)
               = (P_opp − P_now) / (P_opp − P_entry)   [随机游走无漂移]
               = 基数 × 防线引力加成 ≈ 1.05-1.15× [实际]

EV(P_entry) = P(成交) × [W(N) × RR − (1−W(N))]
```

## 二、数值实例 (BTC 42300 防线, 3触)

P_def=42300, P_opp=43500, ATR=200, P_now=42500

| 挂单价 | 距防线 | RR | P(成交) | EV (W=65%) |
|--------|--------|-----|---------|------------|
| 42500(市价) | 1.0 ATR | 3.85 | 100% | 1.91R |
| 42450 | 0.75 ATR | 5.0 | 95.2% | 2.62R |
| 42400 | 0.50 ATR | 6.88 | 90.9% | 3.85R |
| 42350 | 0.25 ATR | 10.45 | 86.9% | 5.97R |
| **42300(防线)** | **0** | **20** | **83.3%** | **10.54R** |

**结论：EV 单调递增——越靠近防线，EV 越大。极端点（防线本身）就是最优。**

---

## 三、为什么单调递增

成交率衰减是线性的（每靠近防线 0.25 ATR，成交率掉 ~3.5%）。  
RR 增长是反比的（分母变小 → 暴涨）。

当防线到对侧的距离 ≫ 防线到当前价的距离时，RR 的边际增长永远压过成交率的衰减。

## 四、2 触防线的两阶段平均 RR

2 触防线不够强，不敢全仓左侧。采用清单的方案：

```
阶段1: 确认 K 出 → 50% 市价进
        入场价 ≈ P_now ± 0.2 ATR
        RR₁ ≈ 1.5-2.5

阶段2: 价格回踩防线 + 再出 pinbar → 50% 限价补
        入场价 ≈ P_def + 0.1 ATR
        RR₂ ≈ 5-10
```

### 概率加权

```
回踩概率 P_retest ≈ 0.6（2触防线，市场常有反复）

有回踩: 平均 RR = (1.5 + 8) / 2 = 4.75
无回踩: 平均 RR = 1.5（只有半仓）

加权 EV = 0.6 × 4.75 + 0.4 × 1.5 = 3.45R

对比纯右侧（全仓市价，RR=1.5）：EV = 1.5R → 提升 2.3 倍
```

## 五、动态防线升级

2 触极点 + 量节点（HVN）在同一条线上（距离 ≤ 0.5 ATR）→ 等效 3 触强度 → **可以直接全仓左侧挂单**。

逻辑：
- 极点防线 = 市场在此拐头了 2 次
- 量节点防线 = 大量真实持仓在此处
- 两者重合 = 持仓人 + 拐头共识 = 准 3 触强度

系统已实现：推送中显示 `🔵左侧挂单(量升级)` 时，表示该 2 触防线被量节点升级为等效 3 触，可直接挂限价单。
