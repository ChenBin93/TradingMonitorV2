# 期权策略线（学习计划之后的策略研究线）

## 起点

学习计划的总结论：方向层全 null、波动层三重强结构（关键位 +7.4pp、高ER +16.3pp、2σ带 +15.9pp@17σ，释放"即启持续缓饱和"）。long-vol 的自然工具=期权。OKX 有 BTC/ETH 期权（European、ctMult=0.01）。

## 数据现实（2026-08-14 核验）

- OKX public API 只服务**在列合约**——过期合约 history-candles 返回 51001，不可拉
- 单合约蜡烛深度 ≈ 3000+ 根 1H（~4 个月，季度合约）
- 周度合约上市 ~1 周 → **合约可用性以蜡烛覆盖为地面真相**（触碰时点无蜡烛=不可交易）
- 期权 K 线日内报价陈旧（小时级重复价）；ETH 期权覆盖断层（08-11 起 vs K 线数据止 08-01）
- 数据层：`data/options.db`（options_data.py 定向下载器）+ 预留未来增量

## c57 第一块砖（2026-08-14）：触碰后买跨式——**拒绝**

- BTC 84 个可用触碰：24h 跨式 P&L **−4.18%** vs 随机时点 null **+2.07%**（显著跑输）
- E1 波动释放 +8.55% 真实复现，但跨式隐含 breakeven +21.12%——**释放已被期权定价，且 IV 对触碰过度反应**（入场后均值回复，vega 损失）
- 结论：**触碰后买跨式不可行**；反向线索（触碰后卖跨式显著优于随机时点卖）留待新预注册（注意 short vol 尾部风险）
- 与 c19/c29"事件后买入不利"同向

**三砖结论**：买侧（事后/事前）连续负，卖侧为正但只是买侧的镜像。**触碰时刻的 IV 高估是系统性的**——波动释放真实（E1 +8.55%）但 breakeven 21.12% 远高于它。

**下一步优先级**：①验证卖侧（扩窗口/标的——数据受限，优先 live-forward 采集；补 vega/theta 逐笔归因）；②long-vol 买侧需换信号框架（如"波动持续期"预测而非"波动突发"预测）或放弃；③所有结论受 n=84/31 与期权 K 线陈旧报价限制，研究级定案需 3 个月以上 live-forward 数据。
