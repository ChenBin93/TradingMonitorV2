## c57 第一块砖（2026-08-14）：触碰后买跨式——**拒绝**

- BTC 84 个可用触碰：24h 跨式 P&L **−4.18%** vs 随机时点 null **+2.07%**（显著跑输）
- E1 波动释放 +8.55% 真实复现，但跨式隐含 breakeven +21.12%——**释放已被期权定价，且 IV 对触碰过度反应**（入场后均值回复，vega 损失）
