# 交易执行清单

> 保持这一页打开，每笔交易按顺序打钩。
> 核心：**三步确认，一个"否"就放弃。**

---

## 收到推送后

```
□ 信号带"✅成型·Pinbar"吗？
   → 没有 = 设闹钟，不急。
   → 有 = 继续往下。
```

---

## 第一步：方向一致？

```
□ 1h 均线排列（EMA9 > EMA21）与信号同向？   是 / 否
□ 4h 均线排列与信号同向？                   是 / 否
   → 一个"否" → 放弃
```

---

## 第二步：防线合格？

```
□ 价格距防线 ≤ 1 ATR？    是 / 否
□ 防线触及次数 ≥ 2 次？    是 / 否
□ 止损距离 ≤ ATR × 1.5？   是 / 否
   → 一个"否" → 放弃
```

---

## 第三步：入场（取决于触及次数）

### 防线 ≥ 3 次触及 — 左侧入场

防线本身的共识强度超过任何确认 K 线。不等 K 线信号，直接进场。

```
□ 全仓限价单挂在防线位置
□ 不需要等确认 K 线——防线就是确认
□ 价格扫到就进，扫不到不强求
```

### 防线 = 2 次触及 — 右侧入场

防线有共识，但不够强。需要确认 K 定位入场时机。

```
第一轮 — 确认 K 出来时：
□ 15m 出现 pinbar / 吞没？   是 / 否
□ K 线方向 = 信号方向？      是 / 否
□ 成交量 ≥ 均量 × 1.2？     是 / 否
   → 三个都是"是" → 50% 仓位市价入场
   → 有"否" → 等下一根，不提前进

第二轮 — 价格踩到防线 + 再出拒绝 K 时：
□ 价格走到防线位置？         是 / 否
□ 防线处又出现 pinbar / 吞没？ 是 / 否
   → 两个都是"是" → 剩 50% 市价补进
   → 价格直接弹上去没踩防线 → 不追，就半仓
```

### 防线 = 1 次触及 — 放弃

一个价格位置不是防线。前面第二步已被淘汰。

---

## 止损 & 止盈

```
□ SL = 防线外侧 0.3 ATR（直接用系统算的值）
□ TP = 系统推送的出场方案：TP1(40%@0.8ATR) / TP2(30%@对侧) / Moon(30%)
□ RR ≥ 2:1？ 是 → 开仓。否 → 放弃
□ 仓位 = 系统算的保证金%（不改）
```

---

## 下单后 — 追踪 & 利润保护

### TP1 之前：不给市场免费送你出局

```
□ 止损不动——保持在防线外 0.3 ATR
□ 不盯盘——15m 的回踩在 1H 上只是正常呼吸
```

### TP1 触发（价格走 0.8 ATR）→ 第一道锁

```
□ 40% 仓位自动止盈（系统推送里标了 TP1）
□ 剩余 60%：SL 移到入场价 + 0.1 ATR（保本+微垫）
□ 不提前移保本——TP1 触发前不动
```

### TP1 → TP2：微结构追踪 + 反向预警

```
□ SL 跟随：每次价格创新高/新低 → SL 上移到最近 15m pinbar 极值外 0.1 ATR
□ 反向预警：回踩 K 线的量 > 前一根推动 K 量的 1.2x → 卖方/买方在此发力 → 全平离场，不追 TP2
```

### TP2 附近（距对侧防线 < 0.2 ATR）

```
出现以下任一条件 → 全平离场，不等 TP2：
□ RSI 15m 背离（价高 RSI 低 / 价低 RSI 高）
□ 连续 3 根小实体 K（压缩）→ 防线在吸收
□ 放量无进展（vol > 2x 但价不走）
```

### TP2 触发（价格到对侧防线）

```
□ 30% 仓位自动止盈（系统推送里标了 TP2）
□ 剩余 30% Moon：SL 移到原 TP1 位置 → 0.8 ATR 跟踪移动止损 → 不设固定止盈
```

### 风控底线

```
□ 不管哪个阶段：永远不开同方向的新仓覆盖正在跑的仓
□ ≥3 触防线被击穿：扛单 = 最大亏损来源
```

---

## 每天收盘

```
□ 每笔交易记一行：币种 / 方向 / 盈亏 / 按清单执行？
□ 当天有 1 笔以上没按清单 → 明天交易量减半
```

---

## 决策树一览

```
  ① 方向一致？
    ├─ 否 → 放弃
    └─ 是 → ②

  ② 防线合格？（≥2 触 + SL ≤ 1.5 ATR）
    ├─ 否 → 放弃
    └─ 是 → ③

  ③ 防线几触？
    ├─ ≥3 触 → 全仓限价挂防线（左侧）。跳过 K 线确认。
    ├─ =2 触 → 等确认 K 出 → 50% 市价进
    │           → 等踩防线 + 再出 pinbar → 50% 补
    └─ =1 触 → 不会到这，前面②已淘汰
```

---

## 触及数速查

| 触及 | 防线强度 | 入场方式 | 本质 |
|------|---------|---------|------|
| ≥3 触 | 强 | 全仓限价挂防线 | 左侧——防线就是确认 |
| 2 触 | 中 | 确认K后 50%市价，踩防线+pinbar补 50% | 右侧——需要K线验证 |
| 1 触 | 无 | 放弃 | 不是防线 |
