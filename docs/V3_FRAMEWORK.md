## 一、交易定位

| 参数 | 值 |
|------|-----|
| 交易周期 | 1H 级别波段，5M 精确入场 |
| 风格 | 日内短线，不持仓过夜 |
| 胜率/盈亏比 | 高胜率，RR ≥ 1.2 |
| 仓位规则 | 10x 杠杆，每笔风险 ≤ 1% 本金 |
| 参考仓位 | `entry_price × 1% / (1H_ATR × 10)` |
| 扫描频率 | 每 5M 整点（对齐 K 线收盘），首次启动 2 秒快速验证 |
| 预警频率 | 每 30 分钟推送 |
| 监控标的 | 44 个 + 可扩展 |

### 止损逻辑

```
SL 缓冲 = 1H_ATR × 0.3
做多: SL = 支撑位 - 缓冲
做空: SL = 阻力位 + 缓冲
无 S/R 时: SL = entry ± 5M_ATR × 1.5
```

止损放在关键防线后面 1H 级别的噪音缓冲区内，只有当结构真正失效时才触发。

### 止盈逻辑

```
TP1 (快锁, 40%): entry ± 5M_ATR × 0.8
TP2 (目标, 30%): 对侧 1H S/R
Moon (追踪, 30%): 剩余仓位追踪止损
```

入场后 +2ATR 触发保本止损移动。

## 二、交易模式

### 模式 1：1H 趋势回调到位

**逻辑**: 1H 有趋势 → 价格回调到防线 → 5M 反转确认 → 顺势入场

| 步骤 | 条件 | 实现 |
|------|------|------|
| 趋势判定 | 1H MA 排列 + ADX ≥ 20 | `_symbol_bias` (4H MA20/MA60+ADX 稳定判定) |
| 防线确认(1) | 1H 极点支撑/阻力（≥ 2 触） | `find_swing_levels(df_1h, lookback=50)` |
| 防线确认(2) | 1H MA20 → 作为第二替代 | `ind_1h["ma20"]` |
| 防线确认(3) | 1H BB 下轨/上轨 → 第三替代 | `ma20 × (1 ± bb_width/200)` |
| 价格到位 | 距防线 ≤ 1.2 × 5M ATR | |
| 反转确认(1) | 5M Pinbar（单向影线 ≥ 60% 振幅） | `pinbar == "bullish"/"bearish"` |
| 反转确认(2) | 5M 双底/双顶（最近 ~15 根 K 线） | `_detect_double_bottom()` |
| 反转确认(3) | RSI + 实体同向 | RSI < 40 + bullish body (做多) |
| 宏观过滤 | 不与 4H 趋势反（除非在 4H 边界） | `✗趋势` 过滤 |
| CheckList | `✓趋势` `✓近支撑/阻力` `✓RS*周期` `✓盈亏比` | |

**信号**: `trend_pullback`

**持仓管理**:
- 🚪入场窗口: 60 分钟
- ⏱持仓上限: 360 分钟
- 💰参考仓位: 基于 1H_ATR × 1 的标准模板

---

### 模式 2：震荡区间边界

**逻辑**: 市场没有方向 → 价格到支撑做多、到阻力做空

| 步骤 | 条件 | 实现 |
|------|------|------|
| 震荡判定 | ADX(5M) < 18 且 ADX(1H) < 18 | `📦震荡` checklist |
| 边界确认 | 价格在 1H S/R 的 1ATR 内 | RSI 极值位置过滤 |
| 极端信号 | RSI ≤ 25 且收阳（做多）/ RSI ≥ 75 且收阴（做空） | `_check_rsi_extreme` |
| 结构位置 | 距 1H S/R ≤ 1ATR (做多需近支撑, 做空需近阻力) | `✗位置` 过滤，不在 S/R 旁的 RSI 极值被丢弃 |

**信号**: `rsi_extreme`

**持仓管理**:
- 🚪入场窗口: 90 分钟
- ⏱持仓上限: 480 分钟

---

### 模式 3：4H 边界反转

**逻辑**: 1H 趋势走到 4H 大结构边界 → 等反转

| 步骤 | 条件 | 实现 |
|------|------|------|
| 边界识别 | 价格距 4H S/R ≤ 2.5 × 1H ATR | `⚠4H边界` checklist |
| 反转信号(1) | 假突破 4H 防线 (上影穿透 + 收盘弹回) | `fakeout` |
| 反转信号(2) | RSI 极端 + 实体确认, 且在 4H 边界 | `rsi_extreme` + `✓4H反转` |
| 宏观处理 | 反转信号不会被 `✗趋势` 惩罚 | 代码中已特判 `has_4h_boundary` |

**信号**: `fakeout` / `rsi_extreme` (counter-trend at 4H boundary)

**持仓管理**: 取决于触发信号类型

---

### 你不做的时候

| 市场状态 | 行动 |
|---------|------|
| 有趋势 + 价格在 S/R 中间 | **不做**：追高追低胜率骤降 |
| 震荡 + 价格在 S/R 中间 | **不做**：区间中间无交易价值 |
| ✗趋势 / ✗方向 | **不做**：信号与宏观反（除非 4H 边界） |
| ⚠拥挤 + 费率极端 | **降仓或不做** |
| ⏰持仓时限到期未达 TP | **主动平仓** |

## 三、信号体系 (6 信号)

所有信号基于**上一根已收盘的 5M K 线**计算（WS 过滤 `confirm=0` 的进行中 K 线）。

### 信号注册表

| ID | 名称 | gate | 方向来源 | 基准置信度 |
|----|------|------|---------|-----------|
| `breakout` | 防线突破 | trend (ADX≥25) | 穿透 S/R 的方向 | 0.60-0.70 |
| `fakeout` | 假突破反转 | any | 反转方向（假上破→short） | 0.65-0.75 |
| `retest` | 回踩确认 | any | 原突破方向 | 0.75 |
| `rsi_extreme` | RSI极值 | any | RSI 超卖→long, 超买→short | 0.85 |
| `volume_spike` | 放量异动 | any | ROC 符号（ROC>0→long） | 0.60-0.90 |
| `trend_pullback` | 趋势回调 | trend (ADX≥25) | 1H 趋势方向 | 0.60-0.78 |

### 信号详细触发条件

#### 1. 防线突破 (breakout)
```
1H S/R 被 5M 收盘价实体穿透 ≥ 0.3×5M_ATR
+ 成交量 ≥ 2×20根均量
+ ADX ≥ 25 (gate=trend)
+ 防线被触碰 ≥ 2 次
```
突破的防线被记录到 `defense_state`，随后可用于回踩确认信号。

#### 2. 假突破反转 (fakeout)
```
1H S/R 被 5M 影线刺穿 ≥ 0.3×5M_ATR 但收盘弹回
+ 穿透幅度 ≥ K线总振幅的 50%（Pinbar 确认）
+ 防线被触碰 ≥ 2 次
```

#### 3. 回踩确认 (retest)
```
前置: 防线曾被动能突破过（defense_state 有记录）
+ 当前价格回到旧防线 0.8×5M_ATR 范围内
+ 出现拒绝形态: 做多需下影线 ≥ 0.3×ATR + 收阳
                 做空需上影线 ≥ 0.3×ATR + 收阴
```

#### 4. RSI极值 (rsi_extreme)
```
做多: RSI ≤ 25 + 5M K线收阳 (+ 必须在 1H S/R 1ATR 内)
做空: RSI ≥ 75 + 5M K线收阴 (+ 必须在 1H S/R 1ATR 内)
```
三种模式复用: 震荡时=模式2, 4H边界=模式3, 均通过 checklist 标记区分。

#### 5. 放量异动 (volume_spike)
```
VR ≥ 3×20根均量 + |ROC| ≥ 0.5%
方向: ROC > 0 → long, ROC < 0 → short
```

#### 6. 趋势回调 (trend_pullback)
```
1H 趋势 (ma_alignment + ADX≥20)
+ 5M 价格靠近 1H 防线 (≤ 1.2×5M_ATR)
  防线优先级: 极点 → MA20 → BB 下/上轨
+ 反转确认 (三选一):
  a) Pinbar ─ 影线≥60%振幅, 方向与趋势同
  b) 双底/双顶 ─ 最近15根K线形成W/M形态
  c) RSI+实体 ─ 做多: RSI<40+阳线; 做空: RSI>60+阴线
```

## 四、预警系统 (5 预警)

预警比信号更早触发，让你提前知道哪些标的值得关注。

| ID | 名称 | 触发条件 | 推送间隔 |
|----|------|---------|---------|
| `near_sr` | 接近防线 | 价格距 1H S/R ≤ 2×5M_ATR | 30 min |
| `coiling` | 蓄力待发 | BB收缩 或 压缩K≥4根 或 TTM≥5根 | 30 min |
| `rsi_approaching` | RSI趋近 | RSI 在 30-35 或 65-70 | 30 min |
| `rs_moving` | RS异动 | 5M RS评分 15-29（未到信号阈值） | 30 min |
| `bb_explosion` | BB爆破 | BB扩张 + TTM刚释放 或 压缩≥8根 | 30 min |

## 六、相对强弱 (RS) 计算逻辑

### 数据流

```
OKX WS (仅已收盘 K 线) → KlineCache → indicators → do_scan
                                                      ↓
                                        sym_close_map (每周期最新收盘价)
                                        sym_prev_maps (多窗口历史价)
                                        sym_atr_map   (每周期 ATR_RS(50))
                                                      ↓
                                        compute_rs() 多窗口加权
```

### 多窗口加权

每个周期用 3 个回看窗口分别算 z-score，按反比权重加权平均：

| TF | 回看窗口 (K线数) | 权重公式 | 实际时间跨度 |
|----|----------------|---------|------------|
| 5M | [3, 5, 10] | 1/w / Σ(1/w) | ~15/25/50 分钟 |
| 1H | [3, 8, 12] | 同上 | ~3/8/12 小时 |
| 4H | [3, 8, 12] | 同上 | ~12/32/48 小时 |

### RS 评分计算

```
for each lookback window:
    btc_roc = (btc_close - btc_prev) / btc_prev × 100
    coin_roc = (coin_close - coin_prev) / coin_prev × 100

    btc_z = btc_roc / btc_atr_pct     (atr_pct = atr/close×100)
    coin_z = coin_roc / coin_atr_pct

    z_diff = coin_z - btc_z

final_z = Σ(z_diff_i × weight_i)      (多窗口加权平均)

rs_score = clip(final_z/3, -1, 1) × 0.5 + (rank-0.5)×2 × 0.5  → ×100
```

**ATR 使用 ATR_RS(50)** 做波动率归一化——周期足够长（5M ≈ 4h, 1H ≈ 50h, 4H ≈ 200h），不被短期趋势波动误导。

### RS 在增强中的作用

| 场景 | 效果 |
|------|------|
| 1 TF RS 同向 | conf ×1.05 |
| 2 TF RS 同向 | conf ×1.10 |
| 3 TF RS 同向 | conf ×1.15 (✓RS三重) |
| RS Δ > 0 (加速) | 显示 ↑+12 |
| RS Δ < 0 (衰减) | 显示 ↓-8 |

## 七、推送前质量过滤

| 过滤项 | 条件 | 作用 |
|--------|------|------|
| min_confidence | < 0.65 | 丢弃 |
| dedup | 同符号同信号同方向 30min | 去重 |
| RR 过滤 | < 1.2 (仅新触发) | 丢弃 |
| ✗方向 | 1H 反向且无强防线 | 丢弃 |
| ✗趋势 | 信号方向与宏观判定反 (且非 4H 边界) | 丢弃 |
| ✗位置 | 做多在阻力附近 / 做空在支撑附近 | 丢弃 |
| 数据陈旧 | WS 断连 > 15min | 丢弃 |
