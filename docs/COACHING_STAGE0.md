> 教练: Claude (opencode)  
> 学员: 短线交易者，持仓 4h 以内，三层周期框架（4h/1h/15m）

## 三层周期框架总览

| 周期 | 角色 | 决策分量 | 用途 |
|------|------|---------|------|
| **4h** | 过滤器（大门） | 5 秒 | 判方向 + 判状态。过了就不再看 |
| **1h** | 核心决策层 | 80% 精力 | 找活跃边界、定止盈目标、判断结构阶段 |
| **15m** | 精确定时器 | 15% 精力 | 找入场信号、定紧止损、具体执行 |

规律：持仓周期缩短，三层窗口对应下移。本框架针对持仓 4h 以内的日内交易。

## 概念 1：趋势方向判断 — 做多还是做空

**应用周期：4h**

### 三个条件

**条件一：均线排列（权重最高）**

- 多头排列：MA5 > MA20 > MA60，三条线向上发散
- 空头排列：MA5 < MA20 < MA60，三条线向下发散
- 无方向：三条线缠绕交叉，或顺序混乱

**条件二：价格位置**

- 多头市场：价格在 MA60 上方运行
- 空头市场：价格在 MA60 下方运行
- 无方向：价格反复穿越 MA60

**条件三：高低点结构（近 10-15 根 K 线）**

- 多头：高点在抬高、低点也在抬高
- 空头：高点在降低、低点也在降低
- 无方向：高点和低点各自混乱

### 判定逻辑

- 三个都指向多头 → 偏多
- 三个都指向空头 → 偏空
- 两多一空 → 偏多（低一档，需更严格条件）
- 两空一多 → 偏空
- 其他 → 中性（不做趋势策略）

## 概念 2：趋势质量 — 强度 + 健康度

**应用周期：4h（只在概念 4 确认为趋势后才做这一步）**

### 趋势强度（三个条件）

**条件一：ADX 的绝对值和方向**

| ADX | 含义 |
|-----|------|
| < 20 | 无趋势 |
| 20-25 | 趋势刚启动，力度弱 |
| 25-35 | 趋势健康，力度中等 |
| 35-45 | 强趋势，力度猛 |
| > 45 | 极端趋势，随时可能衰竭 |

还要看 ADX 在升还是降：
- ADX 上升 → 趋势在加强，可以激进
- ADX 下降 → 趋势在减弱，收紧止盈

**条件二：趋势 K 线和回调 K 线的比例**

- 健康：3-5 根趋势 K 线 + 1-2 根回调 K 线（推三退一）
- 弱：1-2 根趋势 K 线 + 3-4 根回调 K 线（推一退二）

数最近两组。

**条件三：回调深度**

- 浅回调：不破前一根趋势 K 线低点 → 买方强势
- 中回调：破前一根低点但没破前一波段低点 → 正常
- 深回调：几乎吞回整个波段 → 趋势可能快结束了

### 趋势健康度（四个条件）

**条件一：每浪是否还在创新高/新低**

健康：每浪更高（多头）。最新浪没创新高 → 衰竭预警（最早信号，比指标更快）。

**条件二：MACD/RSI 有没有背离**

价格创新高 + 指标不创新高 = 背离。不是立即反转信号，但说明趋势更脆弱了：止损应收紧、不追仓、持仓时间缩短。

**条件三：每浪幅度是否在缩短**

健康：幅度稳定或递增。衰竭：幅度递减——还在涨但每浪推力越来越小。

**条件四：回调是否变深、恢复是否变慢**

健康：浅回调 + 快速回到新高。衰竭：深回调 + 花更多 K 线才回到前高。

### 综合判定

| 条件综合 | 操作 |
|---------|------|
| 都健康 | 正常持仓，正常止盈 |
| 1 项衰竭 | 收紧追踪止损 |
| 2 项衰竭 | 不开新仓，现有仓位收紧止盈 |
| 3+ 项衰竭 | 准备出场 |

## 概念 3：市场状态判断 — 趋势还是震荡

**应用周期：4h**

概念 1 回答"偏多还是偏空"。概念 3 回答"这个偏多/偏空有没有形成趋势"。

两者独立，组合成四象限：

|  | 趋势 | 震荡 |
|---|------|------|
| **偏多** | 顺势做多，趋势策略 | 区间下沿做多，回归策略 |
| **偏空** | 顺势做空，趋势策略 | 区间上沿做空，回归策略 |
| **中性** | 极少见 | 不做，等方向倾向出现 |

### 三个条件

**条件一：ADX 值（4h）**

| ADX | 状态 |
|-----|------|
| < 20 | 震荡 |
| 20-25 | 过渡期（可能转趋势，也可能回震荡） |
| > 25 | 趋势 |

**条件二：价格是否在递进通道（非水平区间）**

- 趋势：价格不回头测试前一波段边界。回调比上次更高（多头）
- 震荡：价格反复回到同一区域，至少各被测试两次

**条件三：布林带形态**

- 扩张 + 价格沿带边运行 → 趋势
- 收缩 + 价格在带内摆动 → 蓄力，可能快出方向
- 平直水平 + 价格在带内来回 → 持续震荡

### 过渡期操作原则

ADX 20-25，布林带刚开始扩张但价格还没离开区间。**不猜、等确认。** 区间持续越久越想"这次该突破了"——但第一次突破大概率是假的。只有看到价格离开区间后没有折返，才算确认。

## 概念 4：支撑阻力的画法

**应用周期：1h**

### 三个有效标准

1. **多次触及**（≥2 次），每次触及后价格反向移动
2. **触及时间在最近 50 根 K 线内**（活跃边界），50 根以前 → 历史参考位，不参与操作
3. **触及后反向移动幅度明显**（至少 1-2 根趋势 K 线距离）

### 水平位优先于趋势线

- 水平线 = 具体价格记忆，"回到这里的人会再次行动"
- 趋势线 = 方向约束，"价格在这个斜向通道内推进"
- 两者在同一区域时，水平线力量更强

### 支撑阻力强度

| 强度 | 特征 |
|------|------|
| 最强 | 水平位 + 均线位 + 整数位的重合处 |
| 强 | ≥3 次触及，最近一次产生强烈反转 |
| 中 | 2 次触及，间隔较长时间 |
| 弱 | 2 次触及但间隔很短 |
| 最弱 | 只被小实体、小影线测试过 |

止损应放在强支撑/阻力外，不是弱边界外。

### 画法流程（1h 图，2 分钟）

1. 找最近 50 根内的波段高点和低点
2. 保留触及 ≥2 次的 → 画水平线
3. 找到最靠近当前价格的上下两条线
4. 上方 = 阻力（止盈参考），下方 = 支撑（止损参考）
5. 标注强度

## 概念 5：入场信号的质量判断

**应用周期：15m**

### 六个质量维度

**维度一：位置（最重要）**

- 位置 A（最优）：在活跃支撑/阻力位附近
- 位置 B（次优）：趋势中回调低点，但不在活跃边界
- 位置 C（不用）：结构中间

位置决定止损宽度 = 仓位大小 = 盈亏比。位置优先于信号质量。

**维度二：信号结构**

- 强 pinbar：影线 ≥ 实体 2 倍 + 收盘在影线端点附近 + 影线突破前一根 K 线
- 弱 pinbar：影线实体差不多 + 收盘离影线端点远

**维度三：确认**

pinbar 出 → 等下一根 K 线。下一根收盘确认方向 → 入场。下一根否定信号 → 放弃。不在 pinbar K 线上抢入。

**维度四：量**

信号 K 线量 > 前 5 根均量 1.2-1.5 倍 = 有资金参与，可信。

**维度五：在趋势的什么阶段**

- 浪 1-2 回调结束 → 高质量
- 浪 3-4 回调 → 中等
- 浪 5+ 或背离后 → 低质量

**维度六：多周期是否一致**

15m 信号 + 1h 也在支撑位蓄力 → 质量翻倍。

### 质量判定

- 满足 5-6 个 → 高，正常进场
- 满足 3-4 个 → 中，减仓或紧止损
- 满足 1-2 个 → 低，不做

### 常见信号默认质量

| 信号 | 默认质量 | 提升到高质量的条件 |
|------|---------|-------------------|
| 15m pinbar | 中偏弱 | + 在 1h 活跃支撑 + 影线长 + 放量 |
| 15m 双底 | 中 | + 两次触及间隔 >5 根 K 线 + 第二次缩量 |
| 15m 压缩突破 | 中偏强 | + 压缩持续 >7 根 + 突破放量 + 1h 顺势 |
| 15m 吞没线 | 中 | + 完全包住前一根 + 放量 + 在支撑位 |
| 15m 均线反弹 | 弱 | + 回调到 1h MA20 缩量企稳后弹起 |

## 概念 6：止损怎么定

**应用周期：15m**

### 止损的三个功能

1. 证明你的判断是错的
2. 决定你的仓位大小（以损定仓）
3. 保护你不被噪音扫出局

三个功能互相矛盾。紧止损 → 仓位大但易被扫。宽止损 → 抗噪音但仓位小。

### 两种定止损方法

**方法一：结构止损** — 放在活跃边界外

做多：入场价 - 最近活跃支撑的距离。做空：最近活跃阻力 - 入场价的距离。

**方法二：ATR 倍数止损** — 正常波动范围外

止损距离 = ATR × 1.5 到 2。适用于没有明显结构的市场。

**优先用结构止损。** 结构止损和你的入场理由直接挂钩：跌破了支撑 = 理由不成立。

### 组合使用

```
1. 先找结构止损位
2. 如果结构止损距离 < 1.5 ATR → 放大到 1.5 ATR
3. 如果结构止损距离 ≥ 1.5 ATR → 用结构止损
```

仓位按实际止损距离（不是结构止损距离）来算。

### 止损移动规则

止损只能往你的方向移动，不能往反方向移动。

推止损的两种情形：
- 价格走到第一止盈（止损等距）→ 剩余仓位止损推到入场价
- 价格形成新的更高低点 → 止损推到新支撑下方

### 止损被扫后的处理

- 被噪音扫：价格短暂刺穿后回来 → 止损太紧
- 真的判断错了：价格突破后持续走 → 判断有问题
- 同一支撑被扫两次 → 支撑已失效，不再同区域做多

## 概念 7：止盈怎么定

**应用周期：1h 定目标，15m 执行**

### 止盈和止损同一个逻辑

止损证明你做多的判断是错的。止盈证明你**继续持仓**的判断是错的——价格到了目标后有更大阻力等着。

### 三种方法

**方法一：1h 活跃边界**

做多止盈 = 入场价上方最近的 1h 活跃阻力。做空止盈 = 入场价下方最近的 1h 活跃支撑。

**方法二：前高前低**

如果 1h 没有明显活跃阻力/支撑，用最近的前一波段高点（做多）或低点（做空）。

**方法三：两段式出场**

- 第一段：价格走到止损等距 → 平仓 50%（锁定利润，剩余零风险）
- 第二段：剩余仓位用追踪止损跟随，让市场决定利润大小

三种可混用：方法一或二定目标，方法三执行。

### 支撑换阻力、阻力换支撑

被跌穿的支撑 → 变成阻力。被突破的阻力 → 变成支撑。

做多止盈用入场价上方遇到的**第一个**活跃阻力（可能正是被跌穿的旧支撑转换而来），不是远处的历史高点。大部分做多信号的力量只够测试最近的上方障碍。

### 盈亏比最低门槛

胜率 < 40% 时：

- 盈亏比 1:1 → 长期必亏
- 盈亏比 1.5:1 → 打平
- 盈亏比 2:1 → 长期盈利
- 盈亏比 2.5:1+ → 明显盈利

入场前必须确认止盈距离 ÷ 止损距离 ≥ 2:1。不达标 = 不做，跟信号质量无关。

### 止盈被触及后

平仓。在止盈点重新评估是另一笔交易，不是原交易的延伸。价格突破原止盈位并回踩确认后，可以在下一笔独立交易中继续做多。

## 概念 8：什么时候不做

"不做"本身就是一种操作，而且是最被低估的操作。

### 六个不做条件

1. **方向倾向不明** — 概念 1 三个条件给不出至少两个同向 → 不做
2. **过渡期** — ADX 20-25，布林带刚扩张但价格未离区间 → 不做
3. **信号在结构中间** — 离上下边界都远，止损只能放远处 → 不做
4. **确认 K 线不来** — pinbar 下一根否定了信号 → 不做
5. **盈亏比 < 2:1** — 止盈目标太近，连最低盈亏比门槛都过不了 → 不做
6. **情绪不对** — 连亏后追本、刚错过怕再错过、疲劳 → 不做

## 概念 9：三周期逐层检查流程（SOP）

### 第一层：4h — 方向 + 状态（60 秒）

```
□ 均线排列？ → 多头 / 空头 / 混乱
□ 价格在 MA60 哪侧？ → 上方 / 下方 / 穿越
□ 近 10-15 根高低点？ → 上移 / 下移 / 混乱
→ 方向倾向：偏多 / 偏空 / 中性

□ ADX？ → <20 / 20-25 / >25
□ 价格通道还是水平区间？ → 递进 / 水平 / 不明
□ 布林带？ → 扩张+贴边 / 收缩 / 平直
→ 市场状态：趋势 / 震荡 / 过渡期
```

**4h 不通过 = 不做。不用看 1h。**

### 第二层：1h — 位置 + 结构（90 秒）

```
□ 画出最近 50 根内的活跃支撑和阻力（触及 ≥2 次）
□ 当前价格离哪个边界最近？
□ 这个边界强度？ → 强（≥3次）/ 中 / 弱

做多：
□ 在活跃支撑附近？
□ 止盈目标（上方活跃阻力）距离 ÷ 止损距离 ≥ 2:1？

做空：
□ 在活跃阻力附近？
□ 止盈目标（下方活跃支撑）距离 ÷ 止损距离 ≥ 2:1？
```

**1h 不通过 = 不做。不管 15m 信号多完美。**

### 第三层：15m — 信号 + 执行（60 秒）

```
□ 信号类型：pinbar / 双底 / 压缩突破 / 吞没线？
□ 信号收盘确认？下一根确认 K 线支持方向？
□ 信号质量 ≥ 4/6 条件？
□ 止损 = 结构边界外，且 ≥ 1.5 ATR？
□ 盈亏比 ≥ 2:1？
□ 仓位按止损距离反算？
□ 情绪状态正常？（不疲劳、不急躁、不追损失）
```

**全部 ✓ = 入场。任何 ✗ = 不做。**

### 完整流程：约 3-4 分钟

每次看盘走这个固定流程，三个周期从上往下，不跳步、不逆行。复盘时每一笔决策路径可追溯。

## 概念 10：K 线微观结构（补充）

### 每根 K 线内部发生了什么

- 下影线长度 = 卖方推进的深度
- 下影线之后实体往上走的幅度 = 买方反击的强度
- 长下影线 + 小实体 + 下一根确认 = 卖方推不下去、买方接手了
- 长下影线 + 下一根反吞回来 = 卖方虽然被反击但还在

### 结构生命周期

结构从形成到完成的自然时长由群体行为决定：

- 15m 结构：6-12 根 K 线（≈ 1.5-3 小时）
- 1h 结构：8-15 根 K 线（≈ 8-15 小时）

趋势由多个浪首尾相连组成。每浪走完一个完整的结构生命周期。成功交易持仓 4h 对应 1h 结构的发展期。

### 突破真假判断

1. 收盘确认：突破 K 线收盘在阻力位上方（盘中刺穿不算）
2. 量能确认：突破 K 线量 > 前 5 根均量 1.5 倍
3. 回踩确认：突破后回调在阻力位（现支撑）撑住了

### 信号保质期

信号在产生它的周期语境下产生，有效期和周期成正比：

| 周期 | 有效期 |
|------|--------|
| 15m | 1-3 小时 |
| 1h | 4-12 小时 |
| 4h | 1-3 天 |

15m pinbar 把目标放大到日级别会失败，因为信号保质期不够。

### 时间本身是一种出场信号

入场后，在信号有效期内价格没走出预期幅度 → 信号失效，出场。不是等到价格打到止损才出，是**时间告诉你信号已过期**。

### 回看窗口规律

| 周期 | 回看范围 |
|------|---------|
| 15m | 30-50 根（约 8-12h） |
| 1h | 40-60 根（约 2-3 天） |
| 4h | 40-80 根（约 10-20 天） |

- 成功交易平均持仓：4h（1h 结构发展期）

---

## 总结

阶段 0 覆盖一个交易者从打开图到入场决策的全部环节：

```
4h：方向倾向 + 市场状态
  ↓
1h：活跃边界 + 盈亏比
  ↓
15m：信号质量 + 执行
  ↓
入场 或 不做
```
