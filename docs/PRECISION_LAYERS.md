# 交易系统精度层 — 完整地图

> 每个模块都可以按"粗→中→细"拆成精度阶梯。精细层的信息无法从粗层推导——因为是不同的数据源。

---

## 确定性乘区（True Independent）

### 1. 方向确认
| 精度 | 工具 | 信息源 |
|------|------|--------|
| 粗 | 单 TF MA 排列 | 时间加权均价 |
| 中 | 多 TF MA 共振（已做） | 多个时间切 |
| 细 | 成交量分布 Profile（VPoC） | 时间×量加权共识 |

Profile 衡量"市场大部分时间在什么区间成交"——公平价。价格在公平价之上且走远 = 趋势真实。与 MA 完全不同的计算逻辑。

### 2. 防线信号（入场确认）
| 精度 | 工具 | 信息源 |
|------|------|--------|
| 粗 | pinbar/吞没 K 线形态 | K 线 OHLC |
| 中 | pinbar + 放量（已做：成型判定） | K 线 + 量 |
| 细 | 足迹图（TradingView） | 价位级买卖方向 |

三者不是三个独立乘区——是**同一个"防线拒绝"的三档精度**。

### 3. 防线位置（S/R 识别）
| 精度 | 工具 | 信息源 |
|------|------|--------|
| 粗 | 视觉水平线 | 人眼 |
| 中 | Swing 极点聚类（已做） | 价格拐头处 |
| 细 | 成交量节点（VPoC/HVN/LVN） | 成交量聚集处 |

极值防线 = 价格在这里反转了 N 次。量节点防线 = 市场花了大量时间/成交量在这里摩擦。两者重合 = 超强防线。

### 4. 市场背景
| 精度 | 工具 | 信息源 |
|------|------|--------|
| 粗 | ADX > 25 → 趋势 | 价格运动 |
| 中 | ADX + MA + 量能（已做） | 多维价格 |
| 细 | 未平仓量（OI）+ 资金费率 | 市场参与者行为 |

OI 升 + MACD 金叉 = 新钱买入。OI 降 + MACD 金叉 = 空头投降 → 反弹，非真多。

### 5. 仓位
| 精度 | 工具 | 信息源 |
|------|------|--------|
| 粗 | 固定 1% | 无 |
| 中 | 静态凯利（已做） | 历史胜率+RR |
| 细 | 动态凯利（滑窗） | 最近N笔胜率+回撤保护 |

### 6. 出场精密度
| 精度 | 工具 | 信息源 |
|------|------|--------|
| 粗 | 固定止盈 | 无 |
| 中 | ATR 移动止损 | 波动率 |
| 细 | 量能耗尽 + 反向信号 | 量价背离 + 信号翻转 |

## 去重提示

以下看似独立的乘区实际是**同一个乘区的不同精度**：

| 外观独立 | 真相 |
|---------|------|
| pinbar / 放量 / 足迹图 | 同一个"防线拒绝"的三档精度 |
| MA排列 / ADX方向 / VPoC位置 | 同一个"方向共识"的不同测量 |
| 固定止盈 / ATR移动 / 反向信号 | 同一个"出场时机"的精度升级 |
