# 模块 1 · 单元 04：时间序列分解（书 CH6 "Components of a Time Series" p.235–236）

## 1. 大白话讲解

任何价格序列都可以拆成四层：

```
价格 = 趋势 + 季节 + 周期 + 随机
```

- **趋势**：长期方向（通常来自投资者对持续新闻流的反应）
- **季节**：日历重复模式（如农产品收获季）
- **周期**：非日历的节奏（经济周期、库存周期）
- **随机**：前三者解释不了的部分

方法论价值：**一个策略要立得住，必须有"真实现象"作为根基**——如果你的利润归因到"随机"那一层，那它就不是利润，是运气。

## 2. 书的原始逻辑

- 三分量 + 残差=随机（"unaccountable price movement"）
- 短趋势来自投资者行为（对持续小新闻的反应）
- 隐含纪律：**先识别现象层，再设计策略层**——策略应该是现象的镜像

## 3. 对接我们的研究

纯方法论，无市场断言。但这条纪律恰好是我们 C 系列全程在执行的：

- c12/c15/c27 测的"波动释放/长记忆"= 波动层的真实现象 ✅
- c21/c23/c25 的全负 = 方向层找不到可归因的现象 ✅（对应"归因到随机层=运气"）
- 我们的三层门禁（GBM null + 分年 + 成本）就是"现象 vs 随机"的判卷机

加密的特殊性：24/7 无日历季节锚，季节层天然缺失——分解只剩"趋势 + 周期 + 随机"三层（与 c12 波动长记忆的"周期感"呼应）。

## 5. 修正理解

书的分层框架完整保留——它和我们的 null 机器是同一枚硬币的两面：书从"现象"出发设计策略，我们从"null"出发验证现象。**本单元无修正，只有确认：模块 1 学到目前为止，每一次"书方法 vs 数据判卷"，都是现象层缺席（方向层）而方法层完整——分解框架解释了我们所有负结果的共同结构。**
