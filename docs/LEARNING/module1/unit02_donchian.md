# 模块 1 · 单元 02：N 日突破与 Donchian 4 周规则（书 CH5 p.222–226 + CH8 p.337–338）

## 1. 大白话讲解

**Donchian 规则（1960 年代，书里最经典的事件驱动系统）**：突破过去 4 周的最高价就买入，跌破过去 4 周的最低价就卖出，永远在场、来回反转。N 日突破是它的参数化版本：把"4 周"换成"N 天"。

它赌的是：**新高/新低是趋势启动的事件**——价格愿意穿越过去 N 天的边界，说明有真方向。N 越大，信号越"重大"（也越少），但风险也越大（入场价到反向触发点越远）。

## 2. 书的原始逻辑

- 规则（p.222）："今日高点越过前 N 日高点买入；今日低点跌破前 N 日低点卖出"；永远在场反转
- **CH8 正式口径（p.337-338）**：窗口止于 t−1（不含当日）+ 收盘价确认（close_t > close_{t−1}）
- **风险随 N 增**（p.222-223）：风险=入场价到反向触发点距离——N 越大风险越大，这是事件驱动区别于时间驱动（均线）的本质特征
- **N<5 不再是事件驱动**（p.222）：变成趋势延续，失去事件意义
- **原油实证（p.224-226，图 5.28）**：1991-2000 最优 N=75 天；2001-2010 最优 N=15 天；合并期 100 天。N=10~100 步长 5、无成本、净盈亏判据——"**所有测试中仅一笔亏损**"
- **自适应 N（Seidel & Ginsberg 1983）**：N_t = N_I × (V_n/V_c)——波动升高时缩短 N
- Donchian 历史地位：1971 年 Playboy 商品交易评测"一打系统之首"；1970 年称 16 年历史最佳

## 4. 实证考证（c41，学习级，2026-08-13）

BTC/ETH 4h+1h；N 日历映射 10~100 日步长 10；双口径（CH5 文字 / CH8 正式）；永远在场反转无成本；GBM 30 种子。

**结果**：

| 假设 | 裁决 |
|---|---|
| H1 "仅一笔亏损"现代版 | 部分：**1h × CH5 口径 10/10 N 全盈利**（GBM null 仅 41.5%±26.4%，超 2σ）——书模式复现；4h 不复现 |
| H2 最优 N 前后半漂移 | ✅ 5/8 漂移 3~5 格——书自述的参数漂移在加密同样成立 |
| H3 风险随 N 增 | ✅ 7/8 maxDD 随 N 单调增 |
| H4 自适应 N 更优 | ❌ 原判据"≥事后最优"违规（见下）→ c43 公平基准重测：走前法 2/4、零优化 N=20 仅 1/4、null 净差仅 1/4——**自适应 N 仍不稳健（仅 BTC 1h 胜出）** |

### H4 基准修正（用户反观点 + c43，2026-08-13）

用户指出 H4 原判据（对比"事后最优固定 N"）违反不可知性：最优 N 会漂移（H2 已证），事后最优是千里眼基准，现实里只能**事前**选定 N。c43 用三个公平基准重比：走前法（前半选 N、后半比）、零优化 N=20（Donchian 默认）、null 净差（海龟汤修正）。结果：**用户批评成立（基准确实违规），但裁决不变**——自适应 N 只在 BTC 1h 稳定胜出，其余 3 配置全输。附带发现：波动缩放确实减少随机游走上的 whipsaw（GBM 自适应 null +0.046 vs N20 −0.283），但这属性已计入净差。

## 5. 修正理解

- **书模式在 1h 复现，但要打折**：关键发现是 GBM 的永远在场反转系统在随机游走上**系统性亏损**（海龟汤：whipsaw 每格 −0.145）——本系统的 null 不是 0 而是负的。真实 1h 的"10/10 盈利"里混着漂移捕获和"打败一个结构上必输的 null"的成分，不是纯方向判断力
- **退出方式是最重要的边界**：c21/c40 的"1:1 固定目标"无优势（全家族一致）；c41 的"持有至反转（无成本）"相对 null 为正。**同样的入场，不同的退出，结论翻转**——这也是为什么书 CH8 强调趋势系统必须"让利润奔跑"
- **书的两个诚实观察都复现了**：参数漂移（5/8）和风险随 N 增（7/8）——书对自己方法的弱点是清醒的，这部分没有时代衰减
- **无成本是致命假设**：1h 口径信号频繁，扣真实成本后"10/10 盈利"大概率归零（c21/c23/c25 的教训）。书的全部分析都建立在无成本上，这是它和我们现实之间最大的缝
- 结合 c42：**书时代的市场（肥尾）确实给过 Donchian 生存的土壤；后书时代的市场（薄尾）里，它只剩无成本下的漂移捕获**
