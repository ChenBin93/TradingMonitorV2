# 模块 1 · 单元 03：回归分析与斜率趋势（书 CH6 p.235–276）

## 1. 大白话讲解

**回归趋势 = 给价格画一条最贴合的直线**，然后用三个数字描述这条线：

- **斜率 b**：每天平均走多少——趋势的速度
- **R（相关系数）**：价格点贴不贴这条线——**趋势的一致性**（同样斜率，平滑上涨 R 高、颠簸上涨 R 低）
- **置信带**：围绕这条线的正常波动范围（±2×残差标准差）——通道

书用一句话说清了斜率为什么不够："同样的斜率，可以是平滑趋势，也可以是噪声乱窜"——所以需要 R 来量"趋势质量"。这是全书的趋势度量学，CH7/CH8 的趋势系统都建立在这套定义上。

## 2. 书的原始逻辑（oracle 逐字核实）

- 方程 Y=a+bX：**X=连续整数 1..n（不是日期！书明确说周末假日断裂连续性），Y=原始收盘价**（Wal-Mart 例用原始价格）；b=(NΣxy−ΣxΣy)/(NΣx²−(Σx)²)
- **r² 阈值**：r²<0.20 回归无实用价值（玉米-大豆 0.83 高、ABX-黄金 0.26 低）
- **两处 R 用法必须区分**：①跨市场相关——去趋势（价格变化 vs 价格变化，p.249）；②**趋势一致性——故意用原始价格 vs 序号，带符号 R**（p.275 明示）
- **置信带**：预测线 ±2.0×残差 sd（95% 用 1.96，惯例 2.0）；买=明日收盘 > 预测线+2×残差 sd
- **跨市场排名**：先指数化（100 基准）再滚动取斜率（60 日例）
- **书自曝的诚实证据**：大豆线性外推失败（预测 $13 vs 实际 $14+）；"对数拟合统计最差却预报最好"——反过拟合教材；黄金期货 20 年 correlogram 15 滞后无一显著（与我们的 c38 lag≥2 近零一致）

## 3. 对接我们的研究（关键澄清）

**"趋势质量高→折返小"这条链，CH6 没写过。** 书只有三个松散组件：

1. R 度量趋势（p.275 只说 R 衡量趋势，没说 R 高→趋势持续）
2. **带外点"预期回归带内"（p.251）——这是均值回归断言**，与我们 c17 触位折返、c23 同向，不是趋势持续断言！
3. "趋势质量→持续"的强版本只出现在 CH1 图 1.7（跨市场截面）——c34 已在该口径复现成功 ✅

所以：c27/c29 击穿的"高趋势质量→触碰折返小"是**我们的直觉外推**，书从未在条件层写过。c44 把两者分开测——**书真实断言（H2 均值回归方向）+ 直觉外推第三次击穿测试（H1）**。

## 4. 实证考证（c44）

预注册（PLAN c44 行）：20 标的 4h；书口径逐字对齐（X=1..n、原始价、带符号 R、±2.0×残差 sd）；双口径（原始价版为主 + 去趋势版稳健性）；H1 高 R 触碰折返差（第三次击穿测试）；H2 带外→带内恢复率（书真实断言）；H3 R-ER 冗余度 + R-波动正交（构造性对照）。

## 5. 修正理解

（c44 完成，2026-08-13）

- **R 轴：未击穿、但也不显著**。高 R 触碰折返差 +2.66pp（方向与直觉一致、达 2pp 门槛），但 GBM 同管线的噪声带 ±9.06pp 把它吞没。三次击穿总表：ER 轴两次击穿（c27 −3.44pp、c29 −5.19pp），R 轴正但 null 内——**"高趋势质量→触碰折返小"在全部轴上不成立**：ER 轴直接反向，R 轴方向对但没有超出随机的证据
- **R 和 ER 近乎正交（Spearman 0.01）**——这是本单元最意外的发现：书的两个"趋势质量"度量测的是**不同性质**。ER=路径效率（绕了多少路），R=线性贴合度（贴不贴直线）。所以 c27 和 c44 不是同一结论的两次验证，而是两个不同轴各自独立的判卷
- **书真实断言（带外回归带内）是机械属性**：81.6% 的带外事件会回带，但随机游走上 84.2% 也会——±2σ 宽带本身让价格大量回带，书 p.251 的"校正"没有超出 null 的内容。与 c23 同命运：均值回归机制真实存在，但无超出结构null的价值
- **方法学收获**：oracle 的"R 由构造即波动正交"预期被数据修正（GBM 上 R-波动构造性 −0.41，真实 −0.10）——"Pearson 归一化即正交"在滚动小窗口下不成立。又一例"构造预期 vs 实测"的差距，GATE 校准兜住了
- **对全书的意义**：CH6 的回归度量学本身是完整的（书定义精确、我们复现逐位对齐），但它作为"趋势质量"的测量，**在条件层不携带方向信息**——与 ER 的境遇一致。书的度量工具都成立，但"度量→方向预测"的桥在加密永续上走不通
