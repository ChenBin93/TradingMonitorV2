# 模块 1 · 单元 01：事件驱动趋势（书 CH5 "Swing Trading" p.182–195）

## 1. 大白话讲解

趋势系统分两大家族，书的 CH5 教的是**事件驱动**这一族：

- **事件驱动**：等"事情发生"才行动。比如"价格突破了前期高点"是一个事件，突破那一刻才入场。没事件就不动
- **时间驱动**：每根 bar 都重新算一遍趋势（比如均线每天更新方向）

事件驱动的好处：**横盘时它闭嘴**。均线在横盘里会来回抽风（书原话："has an agenda"），而 swing 方法在价格没突破任何摆动点时什么也不做。代价是：**风险更大**——入场价到"反向触发点"（那个会证明你错了的摆动点）的距离可能很远。

**摆动点（swing point）**是这一章的核心定义：局部的高点/低点，用一个"摆动滤子"过滤掉小波动。滤子=幅度门槛（点数或百分比），比如黄金 5%：不够 5% 的波动不算摆动。

## 2. 书的原始逻辑

- **Swing filter**：`MSV_t = p × price_t`，且书明确要求**用 MSV_{t−1}（前一天的值）防止前视**——作者对因果性的自觉（我们 c30 系列一直在执行的纪律，书 30 年前就写了）
- **入场规则（保守版，p.188）**："当前上升摆动的高点超过前一上升摆动的高点 → 买入；当前下降摆动的低点跌破前一摆动低点 → 卖出"——永远在场反转
- **风险定义（p.190）**："风险 = 入场点（旧摆动高低点被穿透的价格）与反向入场点之间的距离"——风险可能小如一个摆动反转，也可能很大（快速行情无中间反转）
- **"横盘无 agenda"（p.190）**：事件驱动系统在横盘不行动，是它相对均线的首要优势
- 参照人物：Livermore（止损=前 pivot 穿透点）、Keltner、Wilder 1978

## 3. 对接我们的研究

**两个正面冲突，提前标红：**

| 书的主张 | 我们的证据 | 关系 |

| 保守版入场=破前摆动高点买入 | c21：端点顺势 1:1 未过 GBM | 书该入场规则正是 c21 测过的赌注——书没测，我们测了，没过 |

**关键事实：CH5 全章无回测（💬）**——书的 swing 机制只有机械描述和历史轶事（Livermore 1910-40、Keltner、Wilder 1978），性能证据在 CH8 的系统对比表里。所以我们不是在"复现书的结论"，而是在**补做书自己跳过的检验**。
