# 模块 5 · 单元 01：行为与形态（书 CH14-16）

## 1. 大白话讲解

这三章从"市场行为"的视角看价格：

- **CH14 反向意见**："当所有人都看多，谁还买？"——极端一致的情绪本身是反转信号（但书自己定位为"过滤器，不是交易系统"）
- **CH15 周内模式**：如"周一涨周二跌"——日历节奏的微小偏差
- **CH16 日内交易现实**：**成本是日内利润的最大敌人**；Opening Range Breakout（开盘区间突破，Crabel 1990）——书自测"无成本下所有突破幅度都盈利，20 年后依然"

## 2. 书的原始逻辑（oracle 逐字核实）

- 反向意见（p.642，💬）："戏剧性的行情终结通常归功于公众入场——所有人都确信要涨时，还有谁买？"；COT 持仓分类（📚 引 Jiler 1985）

## 5. 修正理解

（c54 完成，2026-08-13）

- **周内模式：判据不成立**。P[周二跌|周一涨]=58.9%，但置换 null 的 95% 区间宽达 [32.9%, 69.5%]——书的"up Monday down Tuesday"在加密 24/7 上没有超出随机的周内结构（描述层有同向形态，但不显著）。书自己的数据本来就弱（34-66%），我们不冤枉它
- **反向意见代理：无前向信息**。OKX 多空账户比的 Spearman 相关 ≈0.005（null 水平）——账户比不携带方向信息。**注意样本限制**（~180 日 pilot），但结合 c49 H4（funding 也不调节折返），"拥挤度可量化为方向反指"在加密上暂无证据——书的反向意见停在"叙事过滤器"定位（它自己也这么说）是对的
- **5m 日内突破：书的最强负结果之一**。无成本就亏损（BTC N=10 −3.12 vs GBM +0.12）——**5m 级别的反持久直接吃光突破系统**，连成本都不用加。书"无成本所有突破幅度全盈利、20 年后依然"在加密 5m 强烈不复现。这也是对 c31/c38"反持久"最直白的交易层验证：短周期追突破就是送钱
- 本章三断言全负，但**每个负结果都加强总叙事**：方向层无优势从 4h 一路延伸到 5m 和日线——尺度无关
