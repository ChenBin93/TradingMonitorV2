# 模块 8 · 单元 01：多时间框架（书 CH19 p.833–843）

## 1. 大白话讲解

书在这里回答一个组合问题：**指标极少独立成系统，怎么组合？**

核心配方是"双时间框架"：

- **慢框架定方向**：长周期趋势（比如 60 日均线）决定做多还是做空
- **快框架选时机**：短周期振荡器（比如 3 日随机）在趋势方向内**等回撤、找更便宜的入场点**

书的例子：欧元期货一段行情，趋势信号直接入场赚 $2,075；用 3 日随机等回撤入场赚 $6,200——**择时入场把利润放大了 3 倍**。但书自己也老实交代了反例：价格单边直走时，等回撤会"等到一个更差的价格"。

## 2. 书的原始逻辑（oracle 逐字核实）

- 周期比（p.834）："指标周期应远短于趋势周期"——持有期一个月（约 23 个交易日），择时振荡器应在头 3-5 天（10-20%）给机会；"指标本身全亏没关系，利润来自长趋势部分"
- 择时单例（📚 书自算）：60 日 MA + 3 日 raw stochastic，欧元 2010-07~2011-03，$6,200 vs $2,075；**书自曝反例**（单边行情等回撤=更差入场）
- Triple Screen（Elder，💬）：周 MACD → 日随机 <30 → 小时突破，三层漏斗

## 3. 对接我们的研究（本模块核心对撞）

| 书的择时前提 | 我们的证据 | 关系 |
|---|---|---|
| 趋势信号后等回撤入场优于即时入场（dip-buy） | c19：日线顺风回撤恢复率 **−15.4pp**（回撤恢复弱于 GBM） | **正面冲突**：等回撤=等一个恢复率低于随机的事件 |
| "时间视角背书"（大周期方向给小周期择时合法性） | c29：日线 ER 高+方向一致触碰折返**更深**（证伪背书） | 第二次冲突 |
| $6,200 单例 | 恰好是两条证伪所测的口径 | c55 做最小可检验版 |

**书的 $6,200 单例（n=1 市场一段、无成本、无 null）——正是我们两条证伪线所测的"趋势方向正确 + 等回撤入场"口径。** 这是全书最后一个"书有实证"的主张，也是撞墙预期最高的一个。
