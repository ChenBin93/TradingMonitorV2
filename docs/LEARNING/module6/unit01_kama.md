# 模块 6 · 单元 01：KAMA 自适应均线（书 CH17 p.779–799）

## 1. 大白话讲解

简单均线有个尴尬：**固定速度**。市场安静时它太慢（跟不上趋势），市场吵闹时它太快（被噪声骗得来回转向）。

**KAMA（Kaufman Adaptive Moving Average）**的思路：让均线的速度**跟着噪声水平变**——市场安静（ER 高，方向明确）就跑快一点跟紧趋势；市场吵闹（ER 低，来回震荡）就跑慢一点避免被假信号骗。

公式链条（oracle 逐字核实）：

```
sc_t = [ER_t × (2/3 − 2/31) + 2/31]²
KAMA_t = KAMA_{t−1} + sc_t × (p_t − KAMA_{t−1})
```

- ER 高（≈1）→ sc ≈ (2/3)² ≈ 0.44，等价 4 期均线的速度——**快跟**
- ER 低（≈0）→ sc ≈ (2/31)² ≈ 0.004，等价 900 期均线——**几乎冻结**
- 平方是神来之笔：把"快慢"的差距从 15 倍放大到 225 倍

## 2. 书的原始逻辑（oracle 逐字核实）

- 设计前提（p.780）："吵闹市场需要更慢的趋势线"；**"低噪声时价格稳定同向，任何速度都行，因为没有假方向变化"**——这句就是核心对撞点
- 默认参数：ER 窗口 10（收-收）、fast=2/3、slow=2/31、纯收盘价
- 交易规则（p.783）：方向转向信号 + 小阈值过滤（0.1σ）；"周期小于 14，8~10 天最好"
