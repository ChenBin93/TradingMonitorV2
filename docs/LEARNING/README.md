## 单元格式
1. **大白话讲解** — 概念在说什么、解决什么问题

3. **对接我们的研究** — 与 C 系列的印证 / 矛盾 / 空白
4. **实证考证** — 预注册研究（可选）
5. **修正理解** — 数据判卷后的最终版本（考证完成后回写）
