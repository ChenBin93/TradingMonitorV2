# 单元 06：自相关与显著性推断（书 CH2 统计推断 p.43–58）

## 1. 大白话讲解

**自相关**问的是：今天的涨跌，和昨天、前天、上周的涨跌有没有关系？正自相关=趋势有惯性（今天涨明天还涨）；负自相关=反弹倾向（今天涨明天容易跌）；零=无记忆。这是"趋势是否存在"最直接的统计检验。

## 2. 书的原始逻辑

- **Durbin-Watson d 统计量**：d<2 正自相关（趋势持久），d>2 负自相关（反转倾向），d≈2 无自相关
- t 检验/双样本 t 检验：差异显著性
- 样本误差 1/√N：5% 误差要 400 笔——样本量的量化纪律
- 绩效比率全家（Sharpe/IR/Calmar/Sortino）

书把 DW 当作"趋势跟随的土壤探测器"：正自相关是趋势系统利润来源（CH8）的统计学前奏。

## 3. 对接我们的研究

- c31：符号 run 反持久（比硬币短）——符号层的负自相关
- c12：波动长记忆 H≈0.9——**波动**层的强正自相关
- c18：方向≈漂移主导——方向层的"真实增量小"
- 缺失：收益自相关的**完整滞后谱**——本单元 c38 补上

## 4. 实证考证（c38，学习级，2026-08-13）

BTC/ETH 1h/4h/日线 + SPY/黄金/欧元日线，ρ(lag 1..20) + DW + 平方收益自相关，GBM 30 种子逐滞后 95% 区间。

**结果**：

| 假设 | 裁决 |
|---|---|
| H1 加密 1h ρ(1)<0 反持久 | 部分：BTC −0.016 显著负，ETH −0.001 未超 null |
| H2 反持久消失边界 | ✅ **lag 1~2**——所有序列在 k≤2 回到 GBM 区间 |
| H3 平方收益自相关慢衰减 | 部分：ρ²c(1) 全显著 0.10~0.26，但 ρ²c(10) 仅 1h 显著 |
| H4 传统日线符号 | SPY ρ(1)=−0.069 显著**负**——书"趋势市场应正自相关"不成立 |

## 5. 修正理解

- **"近零持久边界" = lag 2**：收益自相关在 lag≥2 全部回 GBM null。方向在两天尺度外无任何可预测结构——这是 c18"漂移主导"的机制解释，也是 c21/c23/c25 全负的统计根源
- c31 的"反持久"其实是**众多微负 lag 的 run 累积效应**：逐 lag 看只有 −0.016（BTC）量级，不能外推为可用的预测力
- **波动层和方向层的自相关完全两套**：方向 lag≥2 近零；波动 ρ²c(1)=0.10~0.26 强正（波动聚集）。市场"记忆"在波动上，不在方向上——与 c12 长记忆一致（注：ρ²c 滞后衰减比 H=0.93 预测快，两度量对齐留待后续）
- 书的 DW 工具本身没问题——是"趋势市场应正自相关"的前提在加密（和 2023-2026 的 SPY）不成立
