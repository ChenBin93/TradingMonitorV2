# 单元 03：数据频率与交易风格（书 CH1 "Deciding on a Trading Style" p.8–9）

## 1. 大白话讲解

书说：先定频率，再定风格。低频数据（周线/日线）噪声低、趋势清晰，适合趋势跟随；高频数据噪声高，适合均值回归和快进快出。风格的根扎在频率上。

## 2. 书的原始逻辑

- 断言"趋势在更少数据点、更长间隔下更容易看清"（图 1.1-1.3 三张原油图）
- 推论：**风格应先定频率**——选错了频率，趋势系统会死在噪声里，均值回归系统会死在单边行情里
- 该断言的验证工具（ER）书只建议未执行

## 5. 修正理解

- "频率决定噪声"不成立（三口径测穿）；"频率决定趋势情节长度"观感真实但机械（c36）
- **修正后的版本**：风格与频率的关系在加密永续不由噪声梯度支撑——频率选择取决于**实际约束**（成本频率、执行速度、监控负担、持仓时间），而非"哪个频率噪声低"
- 书的方法论价值保留：**先定频率再选风格**的决策顺序仍是对的——只是理由从"噪声随频率变"换成"每个频率有各自的成本结构和操作约束"
