# 单元 04：收益计算与年化（书 CH2 "Standardizing Risk and Return" p.48–50）

## 1. 大白话讲解

同一个策略，用不同的收益口径算，结论可以差出每年几十个百分点。收益怎么算、年化怎么化，是研究可复现的前提——口径统一是第一纪律。

## 2. 书的原始逻辑

- 简单收益 (p1−p0)/p0 vs 对数收益 ln(p1/p0)：长期累积下差异显著，对数收益加法可加、统计性质好
- 252 日年化；NAV 复利曲线
- 绩效比率全家（Sharpe / IR / Calmar / Sortino）各自适用场景

## 3. 对接我们的研究

本单元为纯方法论，无市场断言可测。C 系列口径已内化：

- 研究脚本统一对数收益/百分点口径
- MIN_N（书"5% 误差需 400 笔"的 1/√N 教训 → 我们的 MIN_N 门禁）
- 分年稳定性（书"样本误差"思想 → 我们 BY_YEAR 必做）
- 成本行独立（书的多版本绩效口径 → 我们 taker 成本必算）

无（方法论单元）。
