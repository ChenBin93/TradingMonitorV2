# 单元 05：分布矩：偏度与峰度（书 CH2 "Moments of the Distribution" p.37–43）

## 1. 大白话讲解

收益分布的"形状"不只均值方差两个数。**偏度**=分布左右多不对称（右偏=大涨稀有但幅度大）；**峰度**=分布多"肥"（厚尾=极端值比正态多）。书用这两个矩给市场状态画像：什么形状对应什么市场行为。

## 2. 书的原始逻辑

- 商品价格正偏（低价久、高价短）
- **负峰度=趋势/扁平分布，正峰度=横盘/聚集**——分布形状与市场状态一对一映射
- 系统测试峰度 >7~8 视为过拟合警报

## 3. 对接我们的研究

- c13 已证：加密收益右偏 + 下行厚尾（书偏度方向 ✅）
- 峰度-状态映射未测——本单元 c39 补上
- 与 c16（区间留存）关系：书称"峰度符号→状态"是 c16 状态分类的潜在理论根基

## 4. 实证考证（c39，学习级，2026-08-13）

按 c27 的 ER rolling 分位把 BTC/ETH 1h 切成趋势态（高 ER）/横盘态（低 ER），比较各态收益超额峰度，GBM 同管线对照。

**结果**：

| 假设 | 裁决 |
|---|---|
| H1 趋势态峰度 < 横盘态（书方向） | ❌ 不稳定：BTC 高ER +8.94 < 低ER +11.05 ✓，ETH 高ER +19.53 > 低ER +6.44 ✗ |
| H2 真实 vs GBM | ✅ 全部 6 格真实 +6.4~+19.5 vs GBM ≈0——厚尾处处存在 |

## 5. 修正理解

- **书断言不成立**：所有状态的收益都强厚尾（正峰度），**没有任何负峰度状态**。书把"价格水平分布的扁平度"直觉错套到了"收益分布"上——价格在趋势里走成直线（水平扁平），但**收益**依然会偶尔大跳（厚尾）
- 修正后的映射：状态不改变"是否厚尾"（处处厚尾），只改变厚尾的**程度**（且方向因标的而异，无普适规则）
- 峰度不能作为状态分类的理论根基；c16 的状态口径应保持纯行为定义（区间留存），不挂靠分布矩
- 过拟合警报（峰度>7~8）作为方法论提示仍保留价值
