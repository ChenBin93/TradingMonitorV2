# 模块 3 · 单元 01：季节性与周期（书 CH10-11）——跳过考证（用户决定）

## 1. 大白话讲解

书的 CH10-11 讲两件事：**季节性**（日历重复模式，如"5 月卖出"、假日效应）和**周期分析**（非日历节奏，如牲畜的 9-11 月周期）。

## 2. 书的原始逻辑（oracle 已核实过）

- 季节=日历重复；月度数据是大口径（更短周期=更噪）📚
- S&P 月度模式漂移：书自己展示 1982-2010 的夏跌模式消失、"buy in May"不再成立、假日效应（Merrill 1897-1964）
- 周期分解：一阶差分去趋势、12 月 MA 去季节、MESA 最大熵 💬

## 3. 为什么跳过考证（用户决定 + 理由成立）

1. **加密 24/7 无日历锚**：书的所有季节性断言依赖交易日历（周末、假日、月末）——加密没有这些锚点
2. **书自己已经承认模式漂移**：CH10 里作者自己展示"buy in May"失效——季节性断言的保质期问题书自己就有答案
3. **可测部分已被覆盖**：周内/时段效应已在 c49（美股时段量能驼峰）测过；周内方向模式在 M5 的 c54 中顺带覆盖
4. **周期分析无 crypto 对应物**：书依赖基本面锚（牲畜饲养周期、农作物收获），加密无此结构；c12 的波动长记忆（H≈0.9）已是我们宇宙里唯一的"周期感"，且已在波动侧

## 4. 实证考证

无（跳过）。

## 5. 修正理解

**保留书的方法论框架（季节=日历重复），弃用其市场断言（crypto 无日历锚）。** 模块 3 记为一个"跳过但归档理由"的单元——这是学习计划里第一个因"市场结构不适用"而非"数据证伪"跳过的模块。若未来做美股子集的交易，此模块可解冻（书的数据就是美股的）。
