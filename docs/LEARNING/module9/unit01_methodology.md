# 模块 9 · 单元 01：验证、风险与组合（书 CH20-24）

## 1. 大白话讲解

全书的收官章节不教新指标，教**怎么活着**：怎么测试才不会被自己骗、怎么理解运气和技能的区别、怎么分散风险。

四个主题：

- **CH20 噪声的数学**：书说"噪声≈随机数"——近一半价格变动次日反转、25% 连两天、12.5% 连三天（几何衰减）
- **CH21 测试纪律**：**"测试用于取舍，不用于发现"**——先有想法再验证，而不是在数据里挖想法；书用 Kuwait 原油案例解剖"最优参数=贴着单一价格冲击=最脆弱"
- **CH22-23 极端与运气**："价格冲击时相关性→1，分散失效"；LTCM 之死=把过去的冲击都"解释掉"然后死在下一个冲击上
- **CH24 波动稳定与分散化**：按波动率调仓（VF=目标波动/10 日滚动年化波动、滞后一期）；"现实世界的分散化大约只能减半风险"

## 2. 书的原始逻辑（oracle 逐字核实）

- 几何衰减断言（p.869，💬 无源）：50/25/12.5——**书自己定性这是"噪声≈随机数"的基准，不是市场偏离**；附带幅度版（冲击大小也 50/25/12.5）
- 测试纪律（p.907，📚 预注册同源）："Testing should be used for deciding trade-offs, but not for discovery"；Kuwait 解剖（p.973，📚）：最优参数"紧贴一次冲击、牺牲其他所有交易"；"避开过某次冲击的参数对未来毫无意义"
- 冲击相关性（p.994，💬+📚 Lukac 引文）："冲击时相关性→1，因为投资者都在夺路而逃"；12 系统×12 市场月收益相关 0.37-0.81 全显著
- 波动稳定（p.1142-1143，📚 书自示例）：VF=目标波动/年化波动；"更实用的是 10 日滚动年化波动、滞后一期调仓"
- 分散化（p.1101，📚 图 24.1）："1→4 个资产风险下降快，4 个以上边际递减；**现实世界充分分散≈风险减半**"
