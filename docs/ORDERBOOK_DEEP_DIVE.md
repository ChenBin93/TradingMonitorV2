# 交易底层原理 — 订单簿、机构行为与价格运动

> 教练: Claude (opencode)  
> 基于 2026-05-11 的深入讨论

---

## 一、价格运动的本质：拍卖机制

每一笔成交 = 一个人愿意卖 + 一个人愿意买，在那个价格达成交易。

价格不"动"——它只是**上一笔成交的价格**。价格上涨不是因为"买的人多"，是因为**愿意在当前价格卖的人已经卖完了**，下一个想买的不得不往上出价。

市场里同时存在两种参与者：

| | 被动方 | 主动方 |
|---|---|---|
| 行为 | 挂限价单，等着别人来成交 | 用市价单，立刻成交 |
| 风险 | 不一定能成交 | 一定能成交，但价格可能不好 |
| 对价格的影响 | 提供流动性，稳定价格 | 消耗流动性，推动价格 |

趋势 = 主动方持续消耗被动方的挂单，被动方来不及在同一价位补充。

震荡 = 主动方在两个明确的价格之间试探，被动方在两个边界坚守。两边都不愿意离开防线。

## 二、趋势与震荡的订单簿机制

### 趋势的发生

主动方持续消耗被动方的挂单。买方在 43000 吃完卖单 → 打到 43100 → 卖方来不及在 43000 补充挂单 → 买家只能去更高位找卖单。"不是谁赢了，是**谁在补充挂单上比对手慢了。**"

### 震荡的维持

卖方在 43000 挂了大量单。买方试了两次吃不完。买方放弃 43000，退回 42500。卖方也不追——只是防守 43000。买方在 42500 找到了新支撑。

**双方在各自的防线上防守，不在中间位置布防。**

### 突破的发生

防线被消耗完的瞬间 + 反方止损被触发后的连锁效果。

压缩区间 = 防线被反复测试的过程。每一次触碰上沿，卖方补充的卖单越来越少，到最后补不上了 → 防线崩溃。

### 衰竭的原因

主动方在越来越高的价格上找不到被动方了。同时，旧主动方获利离场（卖出）变成新的卖压。

**衰竭 = 主动方在高位找不到足够被动方 + 旧主动方离场变成反方。**

---

## 三、被动方意愿与价格结构

### 防线之间的真空地带

挂限价单有成本——锁定资金、承担反向风险。交易者只在**他认为"价格不太可能继续往这个方向走"的地方**才大量挂单。

- 边界：买方认为"够低了"、卖方认为"够高了" → 挂单密集
- 中间：双方都觉得"不划算" → 挂单稀疏

**趋势启动后价格连续推进——不是因为多方力量暴增，是中间区域本来就没有人防守。** 市价单穿过稀疏区时阻力最小。

这就是你的 1-2 小时持仓的利润来源：从一个防线到下一个防线之间的真空地带穿越时间。

### 防线被反复测试的秘密

防线被触碰多次但不破 = 有人在**持续补充挂单**（机构在建仓）。被触碰一两次就破了 = 没有人在补，存量消耗完就空了。

只触及一次的区域不是支撑——是随机停留。被反复触及并弹起的区域 = 有大参与者在那个价位持续买货。

## 四、支撑/阻力的真实本质

### 活跃支撑 = 机构在接货

机构无法一次性建仓——会推高自己的买入成本。他用限价单在低位慢慢接。他在 42000-42500 挂了买限价单，价格越低挂得越多。

他的挂单本身就是市场的被动方防线。其他交易者不知道"机构在接"，只知道"支撑很强"。

### 假突破的机制（Liquidity Grab）

机构故意撤回一部分买限价单，让价格短暂穿过支撑 → 触发止损单（市价卖单） → 机构在更低位置用限价单接这些止损卖单。

**散户看到的是插针，机构看到的是补了一批便宜货。**

### 派发 = 支撑位因建仓者离开而消失

当机构卖完了，不再需要维持支撑位。支撑位本身体现的不是技术的"支撑逻辑"，是背后那个买家的买货行为。**买家走了，防线自然垮了。**

## 五、不同参与者与估值模型

### 五种挂单人

| 类型 | 估值依据 | 行为特征 |
|------|---------|---------|
| 套保资金 | 成本线 + 目标利润 | 价格无关型，不关心趋势 |
| 量化基金 | 统计模型（VWAP、概率拐点） | 数据驱动，精确价位 |
| 杠杆清算者 | 被迫清算价 | 不是主动决策，是机器执行 |
| 散户 | 情绪 | 缺乏一致性，不形成结构 |
| 机构/大资金 | 估值区间 | 分批建仓，耐心等待 |

## 六、订单簿分层结构

| 层 | 距离价格 | 参与者 | 稳定性 |
|----|---------|--------|--------|
| 近端 | ±0.3% | 做市商 | 不稳定，毫秒级调整 |
| 中端 | ±0.3%~2% | 算法基金、投机资金 | 中等，小时级 |
| 远端 | ±2%~5%+ | 机构、套保、长期持仓 | 稳定，天到周级 |

- 近端不做为操作依据（做市商领地）
- 中端 = 15m 信号捕捉区域（压缩结构）
- 远端 = 1h/4h 强支撑阻力

## 七、清算级联的机制

支撑位下方分布着不同杠杆率的清算单：

```
支撑位 42000 ──── 开仓位、机构接盘
41900 ──── 3x 多单清算线
41800 ──── 5x 多单清算线
41700 ──── 10x 多单清算线（最密集）
```

价格每下移一档 → 触发一批清算（市价卖单） → 推低价格到下一档 → 触发更多清算。

**清算引擎在拆机构建的防线。机构会趁机撤掉部分买单，"放手"让清算发生，以更低价格接货。**

## 九、市场的本质

价格的运动不是"有人拉盘/砸盘"。是由成千上万个人的挂单行为形成的集体痕迹：

- 大资金提供了趋势的基础方向（底层流动）
- 跟随者提供了趋势的延续（中层扩展）
- 散户提供了趋势的末端（顶部量）

K 线和指标是这些行为留下的脚印。你不是在预测价格——你是在检测订单簿上多空力量对比的变化。
