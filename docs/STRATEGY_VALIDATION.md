# TradingMonitor V3 — 策略验证总结（2026-07-31）

> 本文档记录通过回测验证的核心结论、当前策略体系、以及各层过滤的实测数据。
> 数据范围: 20 标的 × 60 天 (2026-06-02 ~ 2026-07-31), 5m/1H/4H
> 验证方法: 1:1 对称盈亏测试 (SL=TP=1×ATR, 测方向判断力) + 完整策略 (SL贴支撑0.1×ATR, TP=2×ATR) + Walk-forward 3折

## 一、核心结论（回测验证）

### 1. 交易策略本身没有方向优势

| 条件 | 1:1 胜率 | 结论 |
|------|---------|------|
| 全部信号（无过滤） | 49.9% | ≈抛硬币 |
| bias 中性 | 48.5% | 无 edge |
| bias 相反 | 45.2% | 负 edge |
| 各信号独立 | 49.0~50.5% | 全无区分 |

**信号形态（突破/回踩/假破/回调）本身不预测方向**——之前正收益全部来自赔率结构（RR 4-6），不是方向判断。

### 2. 交易优势的唯一来源：市场行情判断

| 过滤层级 | 条件 | 1:1 胜率 | 完整策略收益 | 夏普 |
|---------|------|---------|------------|------|
| 基线（无过滤） | — | 49.9% | +67 | 0.6 |
| +4H 宏观趋势 (bias) | bias 与信号方向一致 | 54.1% | +612 | 11.9 |
| +行情状态机 | 顺势距离 ≥0.5 ATR | 59.1% | +1,671 | 43.6 |
| **+RS 方向过滤** | 多头 RS>50 / 空头 RS<-50 | **72%/72%** | +650 | **92.4** |

**Walk-forward 3 折验证（全部通过）**：
- bias 过滤: 52.8% / 56.9% / 52.8%
- 行情状态机: 56.4% / 62.7% / 57.4%
- RS 过滤: 全部正收益, 夏普 86~127

### 3. 1H 趋势无增量信息（被 4H 覆盖）

| 4H bias 一致内 | 1:1 胜率 |
|---------------|---------|
| +1H 一致 | 53.7% |
| +1H 相反 | 54.2% |
| +1H 中性 | 54.6% |

1H 方向一致/相反/中性胜率几乎相同 → **1H 仅作结构角色**（S/R 防线、ATR 风控、入场窗），不做方向判断。

### 4. RS 的完整认知

**RS 本身不是预测器**（纯 RS 分档对未来超额收益无预测力, 实验 1/2/4 验证）；
**RS 是信号放大器**——在顺势行情 + 信号触发的组合下, RS 同向极端大幅提升胜率：

| 多头可交易集 × RS（1:1 胜率） | | |
|------|------|------|
| RS 弱 (<-0.5) | 42.1% | 回避 |
| RS 偏弱 (-0.5~0) | 52.8% | 回避 |
| RS 偏强 (0~0.5) | 62.3% | 可交易 |
| **RS 强 (>0.5)** | **71.5%** | **最优** |

**用户直觉验证**：RS 强 = BTC 跌时抗跌（实验2: 下跌中 Q5 -0.16% vs Q1 -0.43%），回升时领涨需要**信号捕捉转折点**——单纯持有 RS 强币无超额收益，RS 弱币随机做多是接飞刀（35.9%）。

**按信号 × RS 强（多头, 1:1 胜率）**：
- trend_pullback: **90.6%**
- fakeout: 91.7%
- retest: 78.6%
- breakout: 63.6%

## 二、当前策略体系（已落地 live）

### 信号（4 个, 从 6 个降级 2 个）
`breakout` / `fakeout` / `retest` / `trend_pullback`
降级: `volume_spike`（-27, 方向性差）、`rsi_extreme`（-13~-69, 趋势中接飞刀）→ 保留函数待复用, 不再独立推送

### 三层过滤（全部回测验证）

```
第1层: 4H 宏观趋势 (bias)          — bias 与信号方向一致才可交易
第2层: 行情状态机 (market_regime)   — 顺势距离 ≥0.5 ATR (强顺势60.3%/中顺势56.7%)
第3层: RS 方向过滤                  — 多头 4H RS>50, 空头 4H RS<-50
例外: fakeout + 4H 边界反转保留（用户自行判断）
```

### 持仓参数（回测调优）
- SL: 支撑位 − 0.1×1H ATR（贴支撑, 破了就走）
- TP: 入场 + 2.0×1H ATR（回测: S/R 目标太远胜率低, ATR 倍数更优）
- RR 最低: 1.0
- 持仓时限: 48h 内判定（walk-forward 验证 24/48/72h 中 48-72h 最优）

### 推送格式
```
▸ 🔴 ETH 多 趋势回调 ⚡强顺势  RR:2.8:1  ⭐⭐⭐ ...
    S:2900 R:3200  |  ✓趋势 ✓方向 ✓盈亏比
```
- 行情状态标记: ⚡强顺势 / ✅顺势 / ➖贴均线 / ⛔回调 / ⛔无趋势
- RS 显示: `RS:🟢4H+55 🔵1H+30↑+12`

## 三、关键实验记录

### 实验 1: 纯 RS 预测力（无信号）
五分位 RS × 未来 4/8/16h 超额收益: 全部 ≈0（-0.2%~0）→ RS 不预测未来相对表现

### 实验 2: BTC 状态分层
- BTC 下跌时 RS 强: 抗跌（-0.16% vs 弱组 -0.43%）但不领涨
- BTC 上涨时 RS 强: 16h 后 +0.02%（弱组 -0.20%）, 方向符合但幅度小

### 实验 3: 信号×RS 交互
信号触发时 RS 分布对称（各信号 RS 均值≈0）, 非选择偏差；信号入场时 RS 极端胜率高 = 信号捕捉转折点

### 实验 4: RS 定义敏感性
简化 z-diff / ATR 归一化 / live 混合（rank+norm_z）三种定义结论一致 → 非定义问题

### 决定性对照: 随机入场（强顺势内, 无信号）
RS 弱随机做多: 35.9%（接飞刀）→ 证明 RS 需要信号配合

## 五、重大更正：未来函数（2026-07-31 发现并修复）

### 问题
OKX K 线时间戳是 **bar 开盘时间**（10:00 的 1H bar 表示 10:00-11:00）。
回测在 5m ts=10:35 用 `bisect_right` 找到 10:00 的 1H bar 指标——**但这根 bar 要到 11:00 才收盘**，
等于提前使用了未来 25 分钟的价格数据。4H bar 更严重（提前 4 小时）。

### 影响（修复后 20 标的真实数据）
| 指标 | 修复前 | 修复后 |
|------|--------|--------|
| bias 一致 1:1 | 54.1% | **51.1%** (+1.9pp 真实, 弱) |
| 顺势过滤 | 59.1% | 49.8% (**幻觉**) |
| RS 过滤 | 72% | 50-52% (**幻觉**) |
| 完整策略 | +1600 | **-237** |

**结论**：bias/顺势/RS 三层过滤的"高收益"几乎全是未来函数产物。修复后仅 bias 有 +1.9pp 微弱真实 edge。
**live 系统不受影响**（WS 已过滤 confirm=1 只收已收盘 K 线）。

### 修复方式
`_ind_at_series` 增加已收盘条件：`bar_open + bar周期 ≤ ts` 才可用。
缓存 key 升版至 engine_version=8。

## 六、趋势定义研究（2026-07-31）

### 背景
修复未来函数后，"顺势交易"原则未获验证（均线排列定义下顺势≈逆势≈50%）。
怀疑是**趋势定义问题**而非原则问题。

### 多种趋势定义测试（1:1 对称, 20 标的, 无未来函数）

**1. 均线排列 (MA5>MA20>MA60)**：顺势/逆势无差异（49.8-51.9%，无单调性）

**2. MA20 斜率 (20根周期)**：
- 做多: 顺势 48.3% vs 逆势 49.8%（无效）
- 做空: 顺势 50.0% vs 逆势 53.0%（**反向**）

**3. 短动量 (3根=12h)**：做多顺势 47.8% < 逆势 50.3% → **短期反转效应**
（涨多了会回调，12h 动量是反转指标不是趋势指标）

**4. 中动量 (6根=24h)** — **最有效的定义**：
- 做多: 顺势 49.9% vs 逆势 47.7%（+2.2pp）
- 做空: 顺势 52.4% vs 逆势 49.9%（+2.5pp）

**5. 组合 (6根动量 × 价格位置)**：
- 做空 + 动量<0（顺势）: 51.9-54.7% ✅
- 做多 + 动量<0 + 价>MA20（顶部结构）: **45.7%** ✗ 毒药
- 做多 + 动量>0 + 价>MA20: 50.0%

**6. Walk-forward**（做空+6根动量<0）: 49.5% / 54.3% / 51.7%（2/3 折有效）
（做多+动量>0+价>MA20）: 41.8% / 51.9% / 51.1%（1/3 折失效）

### 结论
1. **均线排列是错误趋势定义**——滞后且震荡中翻转，完全无效
2. **24h (6根4H) 动量是更好的定义**——做空侧顺势效应清晰（+2.5pp）
3. **12h 短动量是反转指标**——不能用于顺势
4. 效应真实但脆弱（1-3pp，walk-forward 有折失效），不构成稳定盈利 edge
5. 做空侧趋势效应 > 做多侧（60 天样本）

## 七、层级趋势验证（2026-08-01, 416天数据）

### 背景
60 天窗口 (BTC -10.2%, 日线空头56%) 导致"做空更强"误判。
416 天 (BTC -42.5%, 日线空头53%/多头27%) 补全对照后, 层级趋势规律显现。

### 核心发现: 顺大逆小 (大周期定方向, 小周期做入场时机)

**两级 (日线×4H, 无信号随机入场)**:
- 日线多头: 做多 53.2% vs 做空 47.6% (+5.6pp)
- 日线空头: 做空 56.7% vs 做多 44.2% (+12.5pp)

**三级 (日线×4H×1H)**:
| 背景 | 最佳组合 | 顺势差 |
|------|---------|--------|
| 日线空 | 4H反弹+1H反弹 做空 | **+24.2pp** (62.3%) |
| 日线空 | 4H多头+1H中性 做空 | +24.2pp (62.3%) |
| 日线多 | 4H回调+1H中性 做多 | **+21.4pp** (61.0%) |
| 日线多 | 4H回调+1H回调 做多 | +20.3pp (60.4%) |
| 日线空 | 全顺(4H+1H同空) 做空 | +7.9pp (54.5%) ← 最弱 |
| 日线多 | 全顺(4H+1H同多) 做多 | +1.6pp (51.4%) ← 最弱 |

### 结论
1. **日线是方向决定层** — 顺势 +5.6~12.5pp (决定性)
2. **4H/1H 是入场时机层** — 顺日线 + 逆小周期 (回调/反弹) 入场, 组合达 +20~24pp
3. **全周期同向 (双顺势/三顺势) 最差** — 追涨杀跌, 价格透支
4. **"顺大逆小" = 趋势回调逻辑**, 在每级层级递归成立
5. 之前 60 天"趋势无影响"结论错误 — 因单一日线背景无法分离层级效应

## 十、为什么 5M 没有趋势 — 通道噪声验证（2026-08-01）

### 背景
用户假说: 5M 是通道内噪声, 1H 是通道方向。通道内 5M 每几根来回,
但累计幅度有方向。验证"5M 为什么顺趋势无效"。

### 实验1: K线方向延续性 (阳线后下一根阳线概率)
| 周期 | 延续 | 反转 |
|------|------|------|
| 5m | 44.6% | 55.4% |
| 1h | 47.1% | 52.9% |
| 4h | 47.6% | 52.4% |
→ 所有周期反转主导, 5M 反转性最强。crypto 回撤式波动是共性。

### 实验2: ADX 趋势状态占比
| 周期 | ADX>=25 |
|------|---------|
| 5m | 42.3% |
| 1h | 47.5% |
| 4h | 47.9% |
→ 5M 并非一直震荡, 趋势状态占比不低, 但趋势短命。

### 实验3A: 连续同向K线长度
所有周期平均仅 2 根 (中位 1-2) — 趋势由幅度累积而非方向连续构成。

### 实验3B: 通道假说 (决定性)
1H 通道上升时, 内部 5M 每根K上涨概率: **47.8%**
1H 通道下降时, 内部 5M 每根K上涨概率: **44.7%**
→ 通道方向无法预测内部 K 线方向。通道上升 = 5M 幅度不对称 (涨多跌少),
  而非涨 K 数量多。每根 5M 方向接近随机。

### 结论
1. **用户通道假说完全验证**: 5M 是通道内噪声, 1H 是通道方向
2. **趋势 = 幅度累积, 不是方向连续** — 所有周期连续同向仅 2 根
3. 5M 层顺趋势无效的原因: 单根 K 方向随机性 (55% 反转) 淹没幅度不对称
4. 1H 层有效的本质: 24h 尺度上幅度不对称显著, 足以支撑 1:1 判定

## 十一、幅度不对称机制 — 最终结论（2026-08-01）

### 核心发现
1. **无条件统计下, 任意周期 K 线涨跌对称**:
   - 5m 幅比 1.01 (涨均幅 3.16 / 跌均幅 3.14)
   - 1h 幅比 0.99, 4h 幅比 0.97
   - 涨K占比全部 <50% (熊市背景), 无方向偏置

2. **条件统计下, 大周期有方向时小周期强不对称** (1H通道 × 内部5M):
   - 1H通道上升: 5M涨K 51.0%, 幅比 1.11, 净漂移 **+7.03%**
   - 1H通道下降: 5M涨K 47.9%, 幅比 0.94, 净漂移 **-7.35%**
   - 镜像对称, 条件性极强

3. **用户结论验证**: 不做区分时 K 线对称; 大周期定方向时, 小周期才呈现不对称。

### 为什么 5M 顺趋势 1:1 仍无效
- 5M 的不对称依附于 1H 通道方向, 非自发
- 1:1 判定窗口 288 根 5M 内, 1H 通道多次翻转 → 漂移互相抵消
- 1H 层 24 根窗口内通道相对稳定 → 漂移稳定累积 → 60-67%

### 完整机制链 (全部 416 天验证)
```
日线定方向 (+5.6~12.5pp, 跨越 24 倍仍主导)
  ↓ 通道效应: 大周期方向 → 小周期幅度不对称 (±7%)
      ↓ 1H 层: 通道稳定期 24h → 不对称累积 → 1:1 胜率 60-67%
          ↓ 5M 层: 288根窗口通道频繁翻转 → 不对称抵消 → ~50%
```

### 系统落地含义
- 方向判断: 日线 (唯一方向源)
- 入场时机: 4H/1H 回调 (顺大逆小, +20~24pp)
- 5M: 仅执行确认 (S/R 点位/Pinbar), 不承载方向信息
- 任意单根 K 线涨跌对称 → 裸信号无 edge 的数学本质

## 十二、5M 不对称的传导层级 — 1H 是直接上层 (2026-08-01)

### 实验: 5M 幅度不对称 × 日线×4H×1H 通道 (60天5M)
| 日×4H×1H | 涨K% | 幅比 | 净漂移 |
|----------|------|------|--------|
| ×1H↑ (各日线/4H组合) | 46-49% | 1.24-1.39 | +4.8~+13.0% |
| ×1H↓ (各组合) | 44-46% | 1.04-1.11 | -2.7~-9.0% |
| 4H↑且1H↑ | 48-49% | 1.30-1.33 | +10.8~+11.4% |
| 4H↓且1H↓ | 44-46% | 1.06-1.07 | -7~-9% |

### 结论
1. **1H 通道是 5M 不对称的直接决定层** (1H↑→+13%, 1H↓→-9%)
2. **4H 对 5M 无独立影响** — 同一 4H 状态下 1H 方向差异主导
