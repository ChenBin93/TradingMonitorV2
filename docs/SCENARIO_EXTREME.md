> 教练: Claude (opencode)

## 一、微观场景推演：BTC 1H 回调到 42000 支撑位

### 背景
4h 多头趋势。1h 图上 42000 被触及过两次（强度：中）。价格从 42600 回调，靠近支撑。

---

### 第一阶段：距离支撑 1.2% — 算法基金提前布局

量化基金不等到了支撑再买——竞争太激烈，接不到好价。在支撑位**上方提前挂买限价单**：

```
42500：买入 50 BTC
42400：买入 100 BTC
42300：买入 150 BTC
42200：买入 200 BTC
```

越靠近支撑越加大仓位。挂单不是一次性出现——随价格靠近分批部署。

---

### 第二阶段：距离支撑 0.5% — 做市商调整

做市商同时减卖单厚度 + 增买单厚度。他不判断方向——算法自动计算：反弹概率 × 幅度 vs 风险 → 调整。

净效果：卖限价单减少、买限价单增加。即使没有新买方，价格的下跌速度自减慢——不是因为有人拉盘，是卖的人少了。

---

### 第三阶段：支撑位本身 — 防线测试

机构在 42000 的买入挂单被卖市价单一轮轮消耗。关键问题是：**机构有没有补充新买单？**

- 补了 → 价格弹回来，防线守住
- 没补 → 存量消耗中，防线在变薄

外部看不出来"有没有补单"。只能等**价格行为**确认——这就是"等确认 K 线"的底层含义。

---

### 第四阶段：防线守住 — 反弹的订单簿

机构补单 → 量化基金加仓 → 投机资金跟随 → 做市商减卖单。

买单厚度急剧增加 + 卖单耗尽 → 价格往上弹。

反弹力度 = 机构补单厚度 + 基金跟随厚度 + 卖单耗尽程度。

---

### 第五阶段：防线被破 — 清算级联

机构没补单，或卖压超过接盘能力。价格穿透 42000。

**修正后的清算顺序**（高杠杆先死）：

```
支撑位 42000 ────────── 防线
   ▲ 价格穿透
41950 ────────── 10x 多单清算（最先爆）
41900 ────────── 5x 多单清算
41850 ────────── 3x 多单清算（最后死）
   ▼ 清算卖单逐层往下推
```

高杠杆最脆弱、最先爆。爆出来的市价卖单推低价格 → 触发下一档杠杆 → 层层下压。

机构会**主动撤掉部分买单**，"放手"让清算发生，等更低价再接货。

---

### 第六阶段：清算后

- 机构：撤掉 42000 剩余买单，在 41600-41500 重新挂
- 量化基金：模型更新——支撑被破，概率重组，不追空
- 你（有止损）：止损触发，退出。不参与清算过程
- 你（无仓位）：等下一个防线被测试。42000 降级为历史参考位

## 二、极端行情：订单簿崩塌

### 正常状态的前提：做市商垫着

做市商在买卖两侧挂单，赚价差。承担库存风险——他买到的 BTC 可能立即贬值。平时风险可控（库存周转快）。

在极端波动中，这个前提失效。

---

### 崩塌第一阶段：做市商撤单

价格剧烈下跌 → 做市商刚买到的库存立即贬值 → 风控触发：**大幅撤掉买限价单。**

买单垫子消失 → 卖市价单在真空中坠落 → 价格不是"被推低"，是"在自由落体"。

---

### 崩塌第二阶段：价差爆炸

做市商极度不愿累积库存 → 扩大卖价、缩小买价 → 价差从 0.01% 爆炸到 0.5%+。

你的止损在 41950 → 做市商不在那里接单 → 实际成交在 41800 甚至更低。**滑点不是因为止损设错了，是做市商不在了。**

---

### 崩塌第三阶段：对冲交易的连锁反应

跨交易所套利者发现无法在任何一个交易所对冲。杠杆市场的对冲仓位被自动平仓。多交易所订单簿同时变薄、清算同时触发、做市商同时撤退。不是某一个交易所出问题——是整个市场基础设施在承受系统性压力。

---

### 崩塌第四阶段：买方消失后的自由落体

- 做市商取消全部买单
- 机构暂停补充，等更低价格
- 量化基金模型失效，选择不交易
- 散户想买——交易所可能熔断/限流

剩下的只有**清算引擎产生的市价卖单** + **恐慌散户的卖单**。没有接盘的人。这不再是交易——是在从上往下清理残余挂单。

---

### 重建阶段

崩塌后价格停在新的均衡区 → 有人觉得"够低了"重新挂买单 → 做市商回场（价差缩小、价格稳定）→ 机构在新低部署长期买单 → 逐渐恢复正常。

---

### 对你系统的意义

极端行情时**唯一正确的策略是不参与。**

系统应检测异常信号并自动暂停：

| 检测信号 | 阈值 |
|---------|------|
| ATR 突增 | 1h ATR > 前 20 根均值 3 倍 |
| BB 带宽急剧扩张 | BB 带宽 > 前 20 根均值 2 倍 |
| 连续光脚/光头 K 线 | ≥ 3 根同向无影线 K 线 |
| 量突增但价格不动 | 放量但 K 线实体 < 0.3% |

触发任一条件 → 暂停推送 → 推送"市场异常期暂停监控"。

## 三、我们到底知道什么

所有关于机构行为、清算级联、挂单分布的描述，是**解释模型**，不是事实报告。

模型的价值不在"描述真相"，在**约束行为**：

- 让你在边界入场 → 不在中间入场
- 让你等确认 K 线 → 不等的时候防线可能已经被消耗
- 让你设止损 → 防线破了就退出
- 让你算盈亏比 → 不设不合理的止盈目标

你可能不是"因为理解市场"而盈利，是**因为规则让你避开了常见的亏损行为**而盈利。这两种盈利来源看起来一样，但意义不同。后者不需要模型正确——只需要规则有效。

## 四、已覆盖的完整知识链

```
被动方挂单分布
  → 主动方消耗挂单
    → 防线形成（支撑阻力）
      → 防线被反复测试（机构补单 vs 消耗）
        → 防线突破（消耗完 + 清算级联）
          → 趋势推进（真空地带快速穿越）
            → 下一个防线（止盈目标）
              → 衰竭（主动方找不到被动方 + 旧主动方离场）

异常状态：
  做市商撤退 → 价差爆炸 → 买方消失 → 自由落体 → 重建
```
