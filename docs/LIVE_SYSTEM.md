# Live 监控系统 V2 — 基础版方案 (2026-08-02)

> 本文档是当前 live 系统的完整方案说明。所有结论均经 3 年（1094 天）× 20 标的
> 数据验证（详见 docs/STRATEGY_VALIDATION.md，45 章）。

---

## 一、系统定位

**量化辅助主观交易（quant-assisted discretionary）**：
- 量化层：锁定正收益预期的市场行情（环境/场景/胜率预期），减少盯盘工作量
- 主观层（用户）：方向判断、价格行为解读、订单管理——人工 alpha
- 边界：量化负责"哪里值得看"，主观负责"怎么做、做不做"

验证依据：回测 = 最差情况基线（机械执行+静态管理）；实盘 = 基线 + 人工溢价。
用户实盘 80% 胜率（最终盈亏≥0 口径）与回测的"用户口径"一致。

## 二、架构总览

```
OKX WS (5m/1h/4h, 67标的) → KlineCache → 每5分钟 do_scan:
  1. 多周期指标计算 (compute_indicators)
  2. 多周期 RS 计算 (relative_strength)
  3. 信号检查 (signals.py, 5个信号)
  4. 富化 (_enrich_alert: 场景/RS位置/SL-TP-RR/形态/力量/执行)
  5. 市场状态报告 (market_state.py: 日线→4H→1H 递进 + 多空力量)
  6. Feishu 推送
```

| 信号 | 方向 | Gate | 验证依据 |

## 四、场景引擎（核心，market_state.py）

`scene_of(direction, ind_4h, bias)` → 场景 + 3年胜率表：

| 场景 | 含义 | 3年胜率(严格1:1) | 置信度 |
|------|------|------------------|--------|
| **顺日逆时多** | 日线多+4H回调插曲 | 55-57% (TP2.0=57.8%) | ×1.08 |
| **顺日逆时空** | 日线空+4H反弹插曲 | 57-61% (TP2.0=60.8%) | ×1.08 |
| 顺势多 | 日线+4H同向做多 | 53-55% | ×1.04 |
| 顺势空 | 日线+4H同向做空 | 54-57% | ×1.04 |
| **逆势多** | 日线空时做多 | **45%** | ×0.85 |
| **逆势空** | 日线多时做空 | **47%** | ×0.85 |

关键结论：插曲（顺大逆小）是唯一稳定 edge；做空侧四年稳定强于做多侧
（56-61% vs 54-58%）；方向优势对称（±8.7pp vs 逆势）。

## 五、富化标记（main.py _enrich_alert）

### 场景标记（推送行直接显示）
```
▸ 🔴 BTC/USDT 空 趋势回调 📉4H空 顺日逆时空 57-61%  RR:2.0:1 ⭐⭐ ...
```
- 逆势信号：`⚠逆势多 45%`（醒目警告 + 降权）

### RS 位置依赖（3年验证）
| 场景 | RS条件 | 标记 | 效果 |
|------|--------|------|------|
| 顺日逆时多 | RS>60 | ✓抗跌 | ×1.05 (57.1%) |
| 顺势多 | RS>60 | ⚠过冲 | ×0.93 (52.8%) |
| 顺势空 | RS<-60 | ✓弱势延续 | ×1.04 |
| 顺日逆时空 | RS<-60 | ✓极弱 | ×1.05 (58.3%) |
| 全顺势逆RS | - | ⚠RS逆势 | ×0.90 |

### 可达 RR（按场景，3年参数）
| 场景 | TP | SL下限 | RR |
|------|-----|--------|-----|
| 顺日逆时 | 2.0×1H ATR | 1.0 | ~2:1 |
| 顺势 | 1.5×1H ATR | 1.0 | ~1.5:1 |
| 逆势 | 1.0×1H ATR | 1.0 | ~1:1 |
| **BB反转** | **0.5×1H ATR** | **0.5** | **1:1 (68%场景)** |
- RR>3 显示 `3.0+:1(低胜率)`（防虚高）
- 挂单建议仅当防线 ≤0.5×1H ATR（否则等不到）
- S/R 带距离标签（近/远）
- 仓位按实际 SL 距离计算

### 多空力量（power_balance.py，用户方法论）
- 近30根实体/影线/量能/结构 加权评分（-100~+100）
- 顺日逆时 + 力量同向极端：**✓力量转多/空**（×1.05，3年 62.1% vs 基线 57.1%）
- 反向极端：⚠力量仍多/空（提示）
- 推送行显示 `⚔多头强势(+69) · 优势方减弱`

### 市场状态报告（market_state.py + market_phase.py）
```
日线:📈趋势加速 · 4H:📉趋势末期 · 1H:🔄转换
4H力量:🟢多强3↑ 1H力量:🔴空强36↓
```
- 状态：trend_up/trend_down/range/transition + 阶段(初期/加速/末期)
- **判定窗口 30 根 + 指标历史固定 120 根**（切换灵敏度实验，45章）
- 深回调提示：插曲 + 4H 偏离≥1.5ATR → ✓深回调（55.2% vs 54.2%）

### 4大币 5M 反转 K 执行（3年5M验证）
- 仅 BTC/ETH/SOL/BNB：`✅5M反转K确认` 或 `⏳等5M反转K`（+2.4pp，两次复现一致）
- 其余 16 币不显示（验证无效 -0.4pp）

### 关键位质量分（2026-08-03 研究落地）
- S/R 显示增加质量档：`S:62957(中,2触近质中)`
- 质量分 = 年龄(200-400最优+2/100+1) + touch(≥5:+1/≥3:+0.5) + 4H重叠(+1.5)
- 验证：单调 53.8% → 59.9% → 62.1%（1:1 1ATR/24h 顺日线贴位，+8.3pp）
- 1H S/R lookback 50 → 600（年龄维度需要 200-400 根历史）

### 类型A 贴位标记（2026-08-03 研究落地）
两类关键位框架（3年验证，统一全部历史矛盾）：
| 类型 | 定义 | 胜率 |
|------|------|------|
| A 结构锚贴位 | 最近极值距现价 0-0.5ATR 未破 | **63.7-67.1%** |
| B 水平位贴位 | 老聚类位贴住 | 56.1% 基础 + 质量分 → 62.1% |

- `✓贴位0.3ATR`：最近 swing 贴住未破；插曲场景 → 标注 `·贴位65-67%` + ×1.05
- `⚠位已破-0.3ATR`：最近极值被跌破 0-0.5ATR → **31-40% 灾难**（-25~-30pp），×0.90 降权警示
- 三条件叠加：插曲 + 贴位未破 = 65.5-67.1%
