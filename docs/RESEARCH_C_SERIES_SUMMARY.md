### ❌ 被数据推翻的 prior（验尸价值）

- **方向不可预测 null**（c18/c11）：trend_up 状态进入的 24h 端点方向偏移 -3~-4.6pp——状态条件化携带端点方向信息（但见 Phase 2：不转移为 1:1 命中）
- **B3d 全体区间留存 +8~12pp**（c16 H2）：是 R−S≤2.5ATR 宽度约束效应，无约束时 ≈0
- **波动状态持续 50~60 根**（c12 H4）：实测 16/13 根
- **top5% 方向集中度**（c13 H2）：机械产物（GBM 也 ~89%）
- **触位 1:1 有增益**（c18）：相对无条件基线无增益（-0.31~-0.37pp）

## 4. Phase 2 条件层：4 个预注册候选全部未达发布门槛

| 候选 | 主端点 | 结果 |
|---|---|---|
| c23 趋势态触位逆势 1:1 | ΔWR ≥ +3pp | +0.27pp ✗（端点效应不转移） |
| c21 区间触下沿 limit 小目标 | ΔWR≥+3pp 且 ΔE≥+0.05R | ΔWR 全过（+4.5~6.7pp）但 ΔE 未达（GBM 填充偏置吸收一半）——最接近 |
| c25 状态段首逆势 1:1 | ΔWR ≥ +3pp | +1.83pp 但状态增量 ≈0（全是无条件漂移）；1:1 成本结构性不可达 |
| c22 趋势段首 hold+trail | ΔE ≥ +0.10R | -0.14R ✗（hold 引擎在 GBM 上机械 +0.54R，真实均值回归使净差转负） |

**10 项发布门槛无一项全部通过。按 PLAN exit criteria：Phase 2 封闭，不进入 Phase 3（全回测+live 试点）。**

### 四条方法学教训（写入 PLAN）

1. **端点方向 ≠ 1:1 先碰命中**：描述层的一切方向效应在可交易口径下消失（c17→c23、c18→c25 两次实证）
2. **一切条件化结构在 GBM 上都有机械偏置**：触碰填充 +1pp（c15/c21）、hold+trail +0.54R（c22）——净差化是唯一防线，而这道防线杀掉了所有候选
3. **1h/4h 尺度下真实市场均值回归主导**：不足以覆盖 taker 成本（1:1 的 E[R] ~0.02R vs 成本 ~0.13R）
4. **没有 edge 也是一种结论**：4 个候选全部按预注册裁决、负结果同等归档，无选择性报告

## 5. 对 live 系统的含义

- 预警系统的**描述性价值成立**：关键位=围墙、触碰后波动释放、趋势脆弱性、波动长记忆全部因果验证——预警可以作为市场状态/风险提示
