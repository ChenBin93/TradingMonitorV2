# 市场状态分类 → 策略选择矩阵

> 从公理推导：防线 × 限价单 × 3:1 → 对手方五类 → 燃料池不对称 → 顺势/逆势双引擎
> 
> 核心原则：**识别市场在哪种状态，自动切换到该状态下最优的策略。**

---

## 一、市场环境分类维度

| 维度 | 分类值 | 决定什么 |
|------|--------|---------|
| **4H 方向** (ma_alignment) | 多 / 空 / 中 | 顺势还是逆势——仓位大小、TP 远近 |
| **4H ADX** (趋势强度) | 低(<20) / 中(20-30) / 高(>30) | 燃料是否在烧——趋势能否持续 |
| **1H vs 4H 关系** | 同向 / 反向 | 满仓/半仓/¼仓 |
| **燃料池状态** | 燃烧中 / 衰减 / 耗尽 | 反转概率——TP 该放多远 |
| **防线强度** | ≥3触+量节点 / 3触 / 2触 | 入场方式（左侧限价/右侧等K/不碰） |
| **时段** | 欧美叠加 / 欧洲 / 亚洲 / 周末 | 信号质量——敢不敢重手 |

## 二、多空不对称——底层燃料池差异

| | 多头侧 | 空头侧 |
|---|--------|--------|
| **防守方成分** | 杠杆散户集中 → 连锁爆仓 | 套保者+做市商+费率套利 → 不连锁 |
| **攻击方燃料** | 爆仓链自动补充 → **深** | 散户空头 + 主动砸 → **浅** |
| **趋势衰竭信号** | 买家被反复诱惑→**磨叽** | 杠杆一次性清空→**干脆** |
| **ADX 低时含义** | 继续偏多(回测65%)←不反转 | **反转做多(回测62%)←燃料烧完** |
| **反转后** | 慢——顶部多次确认 | **快**——底部干脆 |

> 回测数据 n=1897 BTC 1H, 16 个月多空完整周期

## 三、六种核心环境 → 六种策略

### 序号对应关系
- 多头侧：环境①-③、策略顺势高RR
- 空头侧：环境④（顺势）、环境⑤-⑥（逆势特化）
- 中性侧：完全按防线强度——无方向偏倚

### 环境 ①：4H 多头 + ADX 中(20-30) + 1H 多头（温和顺势）

| 参数 | 值 | 逻辑 |
|------|-----|------|
| 仓位 | 满仓 | 方向共振 |
| RR | 3-4:1 | 趋势能走远，拿对侧防线 |
| 胜率 | 60-65% | 回测 65%（多头低 ADX 继续偏多） |
| 入场方式 | ≥3 触左侧，2 触右侧 | 防线自然分类 |
| TP 距离 | 对侧防线 | 1.5-2.5 ATR |

**策略：顺势高 RR**——防线挂限价单，拿整段趋势腿。

---

### 环境 ②：4H 多头 + ADX 高(>30) + 1H 多头（强顺势但推力分散）

| 参数 | 值 | 逻辑 |
|------|-----|------|
| 仓位 | 满仓 | 方向仍共振 |
| RR | 2-3:1 | 推力分散，拿不到整段（回测 52%，近中性） |
| 胜率 | 52-55% | 推力在衰减 |
| 入场方式 | 3 触左侧，2 触看信号 | — |
| TP 距离 | 对侧防线 × 0.7 | 不到整段 |

**策略：顺势减预期**——仍做多，但 TP 放近一些，不留 Moon。

---

### 环境 ③：4H 多头 + ADX 低(<20) + 1H 多头（弱多头——高确信）

| 参数 | 值 | 逻辑 |
|------|-----|------|
| 仓位 | 满仓 | 方向共振 + 无逆向压力 |
| RR | 3-4:1 | 回测 65%——最确信的多头环境 |
| 胜率 | 65% | 买家还在慢慢来 |
| 入场方式 | 防线照常 | — |
| TP 距离 | 对侧防线 | 能走到 |

**策略：最优顺势**——这是多头侧最理想的环境。防线做多信号最高信。

---

### 环境 ④：4H 空头 + ADX 中/高 + 1H 空头（顺势做空）

| 参数 | 值 | 逻辑 |
|------|-----|------|
| 仓位 | 满仓 | 方向共振 |
| RR | 3-4:1 | 空头趋势燃料充足（回测 59-60%） |
| 胜率 | 59-60% | 空头侧防守方不连锁——推得远 |
| 入场方式 | 阻力位做空，防线照常 | — |
| TP 距离 | 对侧防线 | 空头腿走得干脆 |

**策略：顺势做空**——燃料还在烧，跟。

---

### 环境 ⑤：4H 空头 + ADX 低(<20)（空头衰减 → 反转）

| 参数 | 值 | 逻辑 |
|------|-----|------|
| 仓位 | 半仓 | 逆大势——仓位减半 |
| RR | 1.5-2:1 | 空头反转快——反弹有力但空间有限 |
| 胜率 | 70-75% | 防守方耗尽了——反转最高信（回测 62%） |
| 入场方式 | 3 触+量节点 左侧 | 防线必须双确认 |
| TP 距离 | 0.8-1.2 ATR | 不等对侧——反转后的早期阻力 |

**策略：逆势反转**——燃料烧光了，防线上接多，不做消耗战。

---

### 环境 ⑥：4H 空头 + ADX 中(20-30) + 1H 多头（逆势摩擦）

| 参数 | 值 | 逻辑 |
|------|-----|------|
| 仓位 | ¼ 仓 | 纯逆势——借摩擦惯性捡一口 |
| RR | 1:1 | 绝不等对侧——逆势方只是消耗 |
| 胜率 | 70-75% | 防守方在防线上接单——反复、小赢 |
| 入场方式 | ≥3 触防线 + pinbar/吞没确认 | 必须强防线 + 确认 K |
| TP 距离 | 0.4-0.6 ATR | 快速——上一轮摩擦的高点/低点附近 |
| SL | 防线外侧 0.3 ATR | 防被穿 |

**策略：逆势快进快出**——RR 1:1，胜率 70-75%。借逆势方反复消耗对手的那一轮惯性捡一口就走。
不是赌反转——是借消耗战里的一颗子弹。

---

### 中性环境：4H Neutral

| 环境 | 策略 | 仓位 |
|------|------|------|
| ADX 高(>30) | 无偏倚——按防线本身强度做双向 | 满仓——防线是唯一信号 |
| ADX 中(20-30) | 接近 50/50——防线按强度做 | 满仓 |
| ADX 低(<20) | 宽松——但只做 ≥3 触防线 | 半仓——无方向锚 |
