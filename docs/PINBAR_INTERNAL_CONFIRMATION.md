# Pinbar 内部确认 — 足迹图与订单簿

> 如何在 pinbar 还没收盘时判断拒绝信号是否真实。

---

## 一、矛盾

左侧挂单（不等 K）→ 拿到防线价，RR 极高。
右侧入场（等 pinbar 收盘）→ 入场价远离防线，RR 打折。
**想在 K 线内部确认时进场，拿到接近防线的价格 + 确认的好处。**

---

## 二、足迹图（TradingView Volume Footprint）

### 在 TradingView 打开

1. TradingView Premium 及以上
2. BTC 15m 图
3. 右键 → 添加指标 → Volume Footprint
4. 设置：显示 Bid×Ask（买方主动 vs 卖方主动）

### 看什么

足迹图上每个价位有两列数字：

```
价格    买方量   卖方量   净差
42400    80      20      +60   ← 上方阻力，均衡
42350    60      35      +25
42300    200      5     +195   ← 防线！买方碾压
42250     3      80      -77   ← 下方全是卖方
```

**在防线价位（42300）：**
- 买方量 200 ≫ 卖方量 5 → **真实拒绝信号**
- 买卖均衡 → 不确定，再等
- 卖方碾压 → 防线要穿了，不进

### 判断时间线

```
pinbar 下影形成中 (K线走了 ~10分钟/15分钟):
  → 打开足迹图
  → 防线价位上买方量开始碾压卖方
  → 拒绝信号已发生 → 不等收盘，现在进
  → 入场价 = 当前价（接近防线，远优于收盘价）
```

---

## 三、没有足迹图的替代：多周期拆解

如果不开 TradingView 足迹图，可以在 OKX/交易所直接看：

**把 15m K 线拆成 3m 或 5m 看：**

```
15m 看到的 pinbar（长下影）:
  拆成 5m 后：

  K1(前5m): 大阴线，价格砸向防线
  K2(中5m): 十字星/小阳线，价格在防线处停下来
  K3(后5m): 阳线实体，价格开始从防线反弹

  → K2 出现时（防线处的停顿 + 小反弹）= 拒绝信号在发生
  → 在 K2 收盘或 K3 开盘时入场
  → 比等 15m 收盘早 5-10 分钟
```

---

## 四、防线价位的深度判断

即使没有足迹图，交易所的订单簿（Order Book / Depth）也能提供部分信息。

在防线上看：
- **买盘深度 > 卖盘深度** → 支撑位有真实买单在防守
- **买盘深度极小、卖盘密密麻麻** → 支撑位是纸糊的，pinbar 不可信

---

## 五、总结

| 工具 | 确认内容 | 进场时机 |
|------|---------|---------|
| 足迹图 | 防线价位买方量 vs 卖方量 | K线未收盘，买方碾压时进 |
| 多周期拆解 | 3m/5m 上的拒绝结构 | 反弹第一根小型阳线收盘时进 |
| 订单簿 | 防线上的挂单深度 | 买盘厚 → pinbar 可信 |

**核心原则：不要在 K 线收盘前猜方向。要在 K 线内部看到真实的证据——防线上有真人买盘在防守。**
