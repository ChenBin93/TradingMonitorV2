## H1–H3 逐条裁决

- **H1 模式不成立, "弱"复现**: 3 市场 (SPY/GC=F/EURUSD=X) × 书窗口/扩展, 分
  周内 P(up) 46.9%~57.0% — 全部落在书报告的全概率带 34-66% 内 (L6-16), 即书
  自评的"弱" (各天都很接近 50%) 忠实复现。但关键的 P[周二跌|周一涨]: SPY
  49.6%/48.6%, GC 50.2%/49.0%, EURUSD 56.5%/49.2% — **无一超置换 95% 区间**
  (L7-17)。EURUSD 书窗口 56.5% (n=186) 是唯一偏高的, 但置换区间宽
  [42.8%, 72.0%] (L15)。**书"确认 up Monday down Tuesday"的模式部分在忠实
  口径下不成立** — 连描述层的周一涨/周二跌形态都不明显 (SPY 书窗口周一 53.1%
  vs 周二 51.7%, 差 1.4pp)。vs c54 加密版 (周一 57.7%/周二 42.6% 描述层可见但
  判据不成立): 忠实口径下形态更弱。
- **H2 方法差异改变结论的强弱**: 固定幅度 k×ATR 突破与 c54 N-bar 版同管线
  对照 (k=0 逐格等于 c54 N=20: BTC −1.5557/ETH −0.9383, L20/L24 与 c54 .out
  一致): 随 k 增大 (事件数 32755→1460), 无成本净收益单调改善 — BTC
  −1.56→+0.99, ETH −0.94→+0.43 (L20-27)。**BTC k=2 加 2.5bp 成本仍正
  (+0.62), ETH k=1/2 成本后接近 0** (L23/L26/L27) — 书"所有突破幅度都盈利"
  在大幅度档方向性复现, 但全部 \|z\|≤2 (最高 BTC k=2 z=+1.76) — **无成本转
  正未超 GBM null 2σ**。c54"无成本即负"的结论是 N-bar 方法特有的; 固定幅度
  方法把无成本结果从"全负"变成"大幅度转正但统计上仍不显著"。
- **H3 书窗口不复现, 扩展成立 (周期依赖)**: 书同市场同周期 (EURUSD 日线
  2010-07~2011-03, 长-only dip-buy): 即时 +610.9 点 / 择时 +374.3 点, 比值
  **0.61** vs 书 $6200/$2075 ≈ **2.99** (L30/L34) — 择时不但没有乘出 3 倍,
  反而**减益** (但两者都为正, 与书同向); z=−0.14 无统计意义; 入场 n=47
  [MIN_N 不足]。**扩展 2012-2026**: 即时 −1157.6 / 择时 +1979.3, gain
  +3137.0, null −108.9±1482.3, **z=+2.19 (>2σ)**, n=101 通过 (L32) — 择时
  显著增益。结论: 书的单例 ($2075→$6200) 在其原市场原周期上**不复现**;
  但择时 (dip-buy) 在 2012-2026 的长周期上表现出 +2.19σ 的增益 — 与 c55 加密
  4h (择时减益) 相反, 周期/市场依赖明显。

## 与 c54/c55/c19/c29/c21/c23/c25 的衔接

- **c54 (加密扩展版)**: H1 忠实口径下形态更弱 (书市场无周一涨/周二跌), 判据
  结论一致 (不成立); H2 的方法对照显示 c54 的 N-bar 全负是**方法特有** —
  固定幅度大幅度档转正 (但同样不显著), 不能把 c54 的"无成本即负"推广为
  "突破类都无成本即负"。
- **c55 (加密 4h 择时减益)**: H3 忠实书窗口同样减益 (0.61×), 与 c55 一致;
  但 EURUSD 扩展窗口 z=+2.19 与 c55 相反 — 择时效果市场/周期依赖, 单例
  (书和 c55) 都不可外推。
- **c19 (−15.4pp) / c29**: H3 书窗口的择时减益与 dip-buy 无优势一致; 扩展
  窗口的正增益是长周期/特定市场现象, 不推翻 c19/c29 的恢复率/时间视角结论
  (度量不同)。
- **c21/c23/c25 (成本吃光)**: H2 中成本仍吃掉大部分小幅度档 (BTC k=0.5
  2.5bp −4.69), 但 BTC k=2 成本后仍正 — 大幅幅度档对成本更不敏感。
