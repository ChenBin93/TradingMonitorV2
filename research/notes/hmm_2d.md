# 二维 HMM 验证 — [收益, 滚动波动率] (2026-08-02)

## 设置
- 观测: [ret=pct_change%, vol=rolling(20).std%], 标准化训练, 反标准化解释
- 3 态高斯 HMM, BTC, 20 次随机初始化, 3 周期
- 预测价值用滤波 (无未来函数)

## 结论
1. **二维 HMM 依然主要学"波动率分档"** (低/中/高波动), 方向 (μ收益) 仍然近零 —
   收益的均值信号在统计上太弱 (信噪比极低), 似然由方差驱动
2. **方向识别不能靠 HMM/收益分布** — 必须靠环境结构 (日线/4H锚 + 场景组合)
3. 二维 vs 单维: 状态更平滑 (停留 17-37 根 vs 单维 2-13 根), 但预测价值相当 (50-55%)
4. HMM 价值定位确认: **波动率状态机** — 与 atr_ratio 分档 (0.7/1.3) 的关系待对照
5. 对照实验待做: HMM波动状态 vs atr_ratio 分档的一致性 —
   若高度一致, 说明 atr_ratio 已覆盖波动维度, HMM 无增量, 研究可转向其他方向
