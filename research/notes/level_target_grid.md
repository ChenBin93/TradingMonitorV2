# 水平位有效性网格验证 (2026-08-03)

> 重大发现：之前矩阵的"36%"是**输出 bug**，真实胜率 56-58%。
> 水平位在顺日线贴位**确实有效**（56-58%，贴位增量 +1.6~+1.9pp，质量分单调 +8.3pp）。

## 两个 Bug 的发现与修复

### Bug 1: level_state_fast/clean/matrix 的显示 bug（36% 假象）
```python
w = sum(res[...][0] ...)   # 赢数
l = sum(res[...][1] ...)   # 命中总数 (win+loss)
nn = w + l                  # BUG! 应为 nn = l
胜率 = w/nn                 # 错误分母 2×win+loss → 显示偏低
```
修复后：36.1% → **56.5%**（做多顺日线）、36.9% → **58.4%**（做空顺日线）。

### Bug 2: level_target_grid 的做空方向 bug
做空赢 = 下跌先到（ft=-1），但 accumulate 统一用 `ft==1` 判赢 → 做空胜率**反向**。
修复：`side == "short"` 时 `first = -first`。

## 正确结论（对称 1:1，T×ATR 目标，W 根窗口，20 syms × 3y 1H）

### 核心表：贴位顺日线胜率（T=1.0, W=24）
| 方向 | 贴位胜率 | 未贴位对照 | 贴位增量 | 插曲 | 质量=低 | 质量=中 | 质量=高 |
|------|---------|-----------|---------|------|--------|--------|--------|
| 贴支撑做多 | **56.1%** | 54.5% | +1.6pp | **57.1%** | 53.8% | 59.9% | **62.1%** |
| 贴阻力做空 | **58.0%** | 56.1% | +1.9pp | **60.6%** | 56.5% | 60.4% | 60.0% |

### 关键规律
1. **水平位 + 顺日线 = 有效**（56-58%），逆日线 43-44%（顺大逆小一致）
2. **贴位增量 +1.6~+1.9pp**（vs 未贴位同状态）——贴位本身有正贡献
3. **质量分单调有效**：做多 53.8% → 59.9% → 62.1%（+8.3pp）
4. **插曲 + 贴位最强**：做空 60.6%（日空4H多）、做多 57.1%（日多4H空）
5. **胜率随 T 单调上升**（T=0.3: 54% → T=2.0: 59-61%）——趋势延续性，大目标更稳
6. **W 影响小**（W=6 vs W=96 差 <2pp，小 T 时几乎无差异）
7. **固定 SL=1ATR 的 EV**：做空 T=2.0 → **+1.25 ATR**，T=1.0 → +0.16 ATR；做多 T=1.0 → +0.12 ATR；**T=0.3 小目标 EV 为负**（SL 过大）

## 回答最初问题
**"贴支撑/阻力关键水平位是否有效？"**
→ **有效**：顺日线贴位 56-58%（1:1 ±1ATR/24h），贴位增量 +1.6~+1.9pp，
质量分单调 +8.3pp，插曲+贴位 60.6%。
之前 63%（刚形成极值）vs 36%（聚类位）的矛盾 = **36% 是输出 bug**，
真实聚类位贴位 = 56-58%，与刚形成极值 63% 的差距 ~6pp（新鲜度溢价，合理）。

## 实盘含义
1. **挂单贴位 + 顺日线**：56-58% 基础胜率（1:1 时），叠加质量分/插曲可达 60-62%
2. **目标选择**：大目标（T≥1.5ATR）胜率更高且 EV 更大（固定 SL 时 T=2.0 EV +1.25ATR），
   小目标（T=0.3）高胜率但负 EV（SL 相对过大）
3. **质量分进 live 的依据成立**：age 200-400 + touch≥3 + 4H 重叠 → 62.1%（做多）/ 60.4%（做空）
