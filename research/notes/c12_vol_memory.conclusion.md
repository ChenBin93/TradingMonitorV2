## 设计偏离 (必须写明)

预注册方法要求 log(ATR) 绝对口径并设 GBM null H≈0.5 门禁。运行前标定
(.out:L20) 证明该口径不可用: 绝对 TR/ATR 与价格水平成比例, 对纯 GBM 的
log(TR) ACF@1=0.96、DFA-H=1.40 (价格随机游走水平污染); 白噪声经 ewm(1/14)
平滑后 H=0.83, GBM log(ATR/close) H=0.84 (ewm 核自带 AR(1) 记忆) — GBM null
≈0.5 在任何绝对/平滑口径下均不可达 (a15 旧脚本已披露同一伪影并用 |r| 规避)。
故: H1 改用 log(TR/close) (原始相对区间, 无平滑, GBM null 实测 0.497),
H2/H3/H4 改用 log(ATR/close) (相对 ATR, 去除价格水平; 在 lag168 处 ewm 核
0.93^168≈0, 不影响 ACF 长记忆测量)。H2 零假设用 permutation (置换) 而非相位
随机化/块 bootstrap — 后者保谱会保留 ACF, 不能作 H2 null; 置换彻底打乱时序,
ACF→0, 是正确 null。
