用户假设: "涨势触支撑容易跌破"可能是趋势末期反转的伴随现象 — 触碰事件
系统性偏 late (A2 的 late 判定含 dev, 回调触支撑 = dev 小/负 → 偏 late),
逆势折返 (B5: 沿趋势概率 46~47%) 不是关键位独立效应。

【S4 — 后期偏置假设被直接否定】
  触支撑 vs 触阻力 距 trend 段起点根数 (中位):
    真实: 3.0 vs 3.0 根 | GBM: 4.0 vs 4.0 根
  → 触碰发生在趋势段早期 (中位 3-4 根), 触支撑与触阻力同样早 —
    "触支撑=趋势末期"的选择效应不存在

【S2/S3 — 控制阶段后逆势折返依然存在 (用户假设不成立)】
  D1 沿趋势方向概率净差 (真实−GBM, 阶段 × 方向 × 侧):
    up_early:       -2.9% / -3.4%
    up_accelerate:  -4.2% / -4.1%
    up_late:        -3.1% / -3.0%
    dn_early:       +0.5% / +0.2%   ← 唯一例外 (≈0, 单点)
    dn_accelerate:  -2.5% / -3.8%
    dn_late:        -3.5% / -4.3%
  → 阶段不是混杂源: 控制后净差保持 (-2.5~-4.3%), 且无阶段梯度
    (late 并不最强) — 逆势折返在趋势各阶段均匀存在

【S1 — 触碰时刻阶段占比 (条件于趋势态内部比较)】
  真实: up_late 全体 28.4% (触碰时刻趋势态占比低于全体因中性触碰稀释,
  需条件化解读); GBM late 占比 (35%) 高于真实 (28%) — GBM 上 A2 分类
  更易 late, 但净差已按阶段分别对照, 不受影响

【结论】
  1. 用户假设 (末期反转伴随现象) 被数据否定: 触碰发生在趋势早期
     (S4), 控制阶段后逆势折返保持 (S3) — 关键位在趋势中具有独立的
     逆势折返效应 (2~4pp)
  2. 逆势折返均匀分布于各阶段 (无 late 集中), 唯一例外 = 跌势 early
     (≈0) — 待观察是否环境交互
  3. B5 结论加强: 趋势中关键位逆势折返 = 真实独立效应, 非混杂
  4. 与 B 系列统一: 关键位约束/拒绝行为在所有行情环境 (震荡/趋势/
     阶段) 均存在; 方向偏好弱 (2~4pp) 且逆势

【待办】

     分层
  2. dn_early 例外深挖 (跌势早期触位无逆势效应 — 熊市交互?)
  3. 逆势折返的交易利用: 趋势关键位逆势 2~4pp + 位移约束 — 与 B4
     非对称小目标思路结合 (非震荡区域版本)
