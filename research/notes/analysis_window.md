# 分析窗口精确化 — 外部 window 参数无实际影响 (2026-08-02 夜)

## 实验设计
- 合成数据 (ground truth): 切换后60根误判 + 稳态误判, 窗口 W ∈ {10..50}
- 真实数据 (20标的 1H): 状态切换频率 (稳定性) + 插曲沿向1:1 (有效性)

## 结果
**A. 合成数据 (修正伪影后 — i 从 130 开始, 保证 df≥120 根)**:
| 窗口 | 切换后60根误判 | 稳态误判 |
|------|----------------|----------|
| 10-50 (全部) | 0.0% | 27.9% |
→ **所有窗口完全相同** — window 参数无实际影响

**B. 真实数据 (20标的 1H)**: 窗口 10-30 状态切换率 35.67次/100根、插曲胜率 57.1% — **完全相同**

## 关键结论
1. **外部 window 参数 (10-50) 对判定结果无实际影响**:
   - analyze_market_state 的 window 只影响门槛 (len<window+30) 和 body 统计 (固定 3/13 根)
   - 判定核心靠 ADX(14)/MA20/MA60/动量(10根) — 这些由**指标参数**决定, 与外部 window 无关
2. **真正的"判定窗口" = 指标自身的参数窗口**:
   - MA20 (20根) / MA60 (60根) / ADX(14) / 动量(10根)
   - 有效判定尺度 ≈ 20 根 (MA20 + 动量10 主导)
3. **与记忆窗口研究一致**: 方向记忆 ~20 根 ↔ MA20 窗口 ✓
   指标设计 (MA20/动量10) 恰好匹配方向记忆尺度 — 现有配置合理
4. **"精确化分析窗口"的正确对象是指标参数** (MA周期/动量窗口/ADX周期),
   不是外部 window 参数 — 待办: 指标参数调优 (见计划)

## 方法论教训
- 第一版 A 部分"稳态误判随窗口单调上升"是伪影:
  序列开头 (i<130) df 不足门槛 → 判定 empty → 误判, W 越大 empty 范围越大
- 修正: 保证 df 长度充足后再比较 — 所有窗口一致
