# 水平位质量定义 — 什么构成"好的关键位" (2026-08-03)

## 金标准
插曲环境 + 贴聚类位 (0<=dist<0.5ATR) 的 1:1 胜率 (沿日线方向, 20标的 3年, n=20399, 基线56.2%)

## 结果

### 直觉1: touch 次数 (多次打到并反转=优质; 太多会被打破?)
| touch | n | 胜率 | Δ |
|-------|------|------|-----|
| 2 | 5363 | 54.2% | -2.0 |
| 3-4 | 6217 | 56.3% | +0.1 |
| 5-7 | 4283 | **57.7%** | +1.5 |
| 8-10 | 1947 | 55.5% | -0.7 ← 回落苗头 |
| 11+ | 2589 | **58.2%** | +2.0 |

### 直觉2: 位年龄 (重要波段高低点=长期关键位)
| 年龄 | n | 胜率 | Δ |
|------|------|------|-----|
| 5-50根 | 10855 | 56.0% | -0.2 |
| 50-100根 | 2943 | 57.0% | +0.8 |
| 100-200根 | 2305 | 57.1% | +0.9 |
| **200-400根** | 589 | **63.5%** | **+7.3** ← 显著跃升 |
| 400+根 | 0 | (300根lookback上限) | - |

### 交互与方向
- touch>=3 + 年龄5-200: 57.3% (+1.1); 刚形成(0-5根)无论touch: 54.5% (-1.7)
- 做多贴支撑 55.5% vs 做多贴阻力(错位) 53.6% (+1.9pp 方向正确略优); 做空侧无差异

## 核心结论: "好的关键位"操作性定义
```
优级: 年龄 200+ 根 且 touch>=3  → 63.5% (+7.3pp)
良级: 年龄 50-200 根 且 touch>=3 → 57.1-57.3% (+0.9-1.1pp)
一般: 其他 (touch 2, 年龄<50)   → 54-56% (≈基线)
差:   刚形成 (0-5根)            → 54.5% (插曲中贴新位 = 插曲进行中)
```

### 关键认知: 两类锚的互补
1. **单点极值锚** (最近swing高低点, 之前研究): 刚形成(0-5根)最强 63-70% —
   反转点信号 (新低/新高刚形成 = 反转确认)
2. **聚类位锚** (多次触及水平位, 本研究): 老而强(200+根)最强 63.5% —
   关键位信号 (长期有效的位 = 重要波段高低点)
→ 交易中: 反转点看刚形成的极值, 关键位看老而强的聚类位

### 用户直觉验证
- 直觉1 (多次反转=优质): ✓ touch 3+ 开始有效, 5-7 最佳之一; 8-10 回落苗头 (11+ 回升, 需更长lookback确认拐点)
- 直觉2 (重要波段高低点): ✓✓ 年龄 200+ 的位 = 63.5% — "重要高低点"的量化形式
- 方向正确性: 做多贴支撑略优, 做空侧无差异
