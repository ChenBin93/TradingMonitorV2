A1.5 市场记忆结构结论 (2026-08-03, 描述性, 无未来函数, 20 标的 × 3 年 1h/4h)
═══════════════════════════════════════════════════════════════════════

回答: 当前 K 线受多大窗口影响? → 分层的: 方向层无记忆, 波动层月级, 量能层小时级

【① ACF 影响窗口】
- |r| (波动聚集): ACF@1=0.26 弱相关, 128根后仍 0.05 显著 → 弱但极长尾 (>7天/1h, >28天/4h)
- log(ATR): ACF@1=0.998, 168 根未跌破 0.5 → 超长记忆 (>7天 / >28天)
- range: 半衰期 2 根 (1h) → 日内范围影响 2-4 小时
- volume/log vol: 半衰期 2-6 根 → 量能影响 2-16 小时
- 所有序列显著窗口均达 168 根测试上限 (弱相关长尾普遍存在)

【② PACF 直接影响】
- |r| 与 log(ATR) 排除中间传导后, 直接影响仍延伸至 43-48 lag (测试上限)
- 含义: 不是简单 AR(1) 短记忆, 是多尺度结构 (各频率层都有贡献)

【③ DFA-Hurst — 两个独立方法互相印证】
- 收益 H≈0.49 (随机游走, 无方向记忆) → 与 A1a (方向记忆不存在) 独立互证
- 波动 |r|累计 H≈0.75-0.80 (强长记忆) → 与 A1b (ACF 半衰期) 独立互证
- 结论: 波动长记忆是双方法确认的稳健事实, 方向无记忆同样是双方法确认

【④ 小波能量谱】
- log(ATR) 能量 99.6% 落在近似层 (>32h / >128h)
- 含义: 波动水平的变化主要由最长时间尺度过程驱动, 2-32h 高频层几乎无能量
- 波动无显著日内/小时级周期成分 (至少在 log(ATR) 中)

【⑤ Granger 因果 (过去→现在, 单向)】
- 量能→波动 与 范围→波动: 20/20 标的显著, 最佳 lag 1-2
- 含义: 过去 1-2 根的成交量/范围对当前波动有即时预测力 (经典量价关系)
- 注意: lag1 需已收盘才能用, 实时无操作价值; 但确认"量能的影响窗口=1-2根"

【⑥ 波动状态持续性 (ATR 三分位)】
- 1h: 低波动持续 58h / 高波动 50h / 中波动 26h; 自保持 0.95-0.98
- 4h: 低波动 222h (9.3天) / 高波动 189h (7.9天) / 中波动 100h (4.2天)
- 状态跳跃: 低↔高 直接转移概率 0.00 — 必须经过中波动 (层级转换结构)
- 时间对齐: 1h 与 4h 的状态持续时长按时间不对齐 (58h vs 222h) → 多尺度独立演化

对 A2 的直接输入

1. 波动维度是分层记忆: 短期分位测水平 (30-60根), 长期状态由月级记忆决定 →
   A2 状态特征建议 短分位 + 长分位 组合, 单一窗口不够
2. 状态层级转换 (低↔高必经中) → "转换状态"定义有实证依据
   (transition 是 低/中/高 之间的中间态, 不是任意跳变)
3. 量能/范围 → 波动 的即时影响 (lag1-2) 可作 A2 附加特征维度
4. 波动状态平均持续 2-9 天 → A3 状态条件胜率研究的样本天然充足
   (每标的每年 ~150-200 次状态进入, 20 标的可满足 MIN_N)
5. 方向维度再次确认无记忆 (H=0.49) → A3 若发现方向 bias 必来自状态条件,
   不是任何形式的动量/均值回归特征
