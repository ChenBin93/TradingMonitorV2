- **H1 支持依据**: 触碰留存 w=6 净差 4/4 组合 ≥ +3pp (+4.0~+7.0pp), 且随 w 衰减但
  w=12/w=24 全部组合仍为正 (+1.8~+5.2pp)。分年 2024/2025/2026 中 touch-w6
  真实>GBM 的年份格 11/12 (唯一反例为 1h(2,0.3) 2025 年 49.1% vs 49.7%,
  .out:L66) — 触碰边界后价格更倾向留在 [S,R] 双边界内, 因果区间口径下成立。
- **H2 否定依据**: 无宽度过滤的"全体区间 bar"留存净差 w=6 在 −1.2~+1.0pp 之间,
  w=24 全部转负。真实区间宽度 (ATR mean 3.1~4.3, .out:L19/L34/L49/L64) 明显
  窄于 GBM (5.1~6.5, 同 L 行) — 更窄的区间机械上更难留存, 但真实全体留存仍与
  GBM 持平 (w=6 真实 62.9~71.7% vs GBM 64.2~70.8%, .out:L9/L24/L39/L54) —
  宽度差异与"贴壁"效应互相抵消, 原始口径净差 ≈ 0。B3d 的全体净差 (+8~+12pp)
  依赖其 R−S ≤ 2.5×ATR 宽度约束 (见设计偏离), 该约束下的结论在无约束因果
  定义下不成立。
- **H3 支持依据**: 触碰后 alive 连续存续段, 真实 mean 比 GBM 长 +2.6~+4.4 根
  (4/4 组合), 中位亦更高 (真实 4.0~6.5 vs GBM 3.0~4.0, .out:L12/L27/L42/L57)。
- **H4 支持 (边界) 依据**: GBM 反向概率系统性高于真实 (GBM 53~57% vs 真实

  无信息市场; 方向维度无正净差。唯一两处正净差 (down +0.6pp, range +2.2pp)
  均为 4h(3,0.5) 组合, 量级小且 16 格多重比较下不足为特异性证据。

## 与 B3d 旧结论对照 (B3d 于 2026-08-12 作废, 仅形状参照, 不作证据)

- **H1 (触碰留存)**: B3d 旧 w=6 净差约 +5~+9pp (4 组合), 本次 +4.0~+7.0pp —
  方向一致、量级偏低约 1~2pp, 与预注册"打折重验"预期一致。因果 alive 语义
  (conf 窗口闭合) 与更严格的边界触碰样本定义下, 触碰延续性依然成立。
- **H2 (全体区间 bar)**: B3d 旧约 +8~+12pp, 本次 ≈ 0 (w=6) 至负 (w=24) —
  差异主因是定义: B3d 全体样本限定 R−S ≤ 2.5×ATR (区间窄), 本次按任务定义
  不加宽度约束 (真实宽度 3.1~4.3 ATR mean)。宽度约束移除后, 全体留存净差
  消失 — 该效应是"窄区间"效应, 非普适区间性质。
- **H3 (剩余存续)**: B3d 旧 Δmean 约 +2~+5 根, 本次 +2.6~+4.4 根 — 同量级
  复现。
- **H4 (趋势×反向)**: B3d 旧涨/跌状态净差全部为负, 本次 16 状态格 14 格 ≤ 0
  (up/down 7/8 ≤ 0) — 方向无特异性的结论形状一致; 分层变量不同 (B3d 用 120
  根收益方向, 本次用 state_features 状态), 数字不可直接对比。
- 汇总: 触碰条件化下的区间延续性 (H1/H3) 在因果口径复现; 非触碰的全体区间
  延续性 (H2) 在无宽度约束因果口径下未复现 — 区间延续性是"触碰/边界"特异
  的结构事实, 且与方向无关 (H4)。

## 设计偏离 (相对 B3d/B2c — 详见脚本 docstring)

1. **无宽度/LIFE 过滤**: 区间 = 逐 bar 最近成对活跃位 + 双侧 causal_confirmed
   存续, 不设 R−S ≤ 2.5×ATR 与位带寿命上限 — 这是 H2 与 B3d 差异的直接来源
   (宽度诊断见上)。按任务定义执行, 未按 B3d 参数化。
2. **alive 语义因果化**: B3d 用 confirmed[c] (c<t) 直接判定存活 (确认窗口
   c+24 未闭合 → 泄漏); 本次仅 conf∈[t-60,t-24] 计为已知, [t-23,t] 内 confirmed
   的触碰样本剔除而非视为存活 (B2c/B2d 索引/泄漏 bug 的干净替代)。
3. **H4 分层变量**: 本次用 state_features.state_series 语义 (向量化复现, GATE
   逐位对拍错位 0, .out:L2); B3d 用 120 根收益方向。方向结论仅形状参照。
4. **触碰样本定义更严格**: 仅计"区间边界触碰" (触碰位带 == 逐 bar 最近边界),
   H1/H3 按 bar 计、H4 按触碰侧计 — n 比 B3d 对应口径小 (本次 n 9131~11739
   触碰样本 vs B3d 6792~4384)。
5. **性能**: 趋势状态/ATR/ADX 向量化复现 (布尔掩码改写规避 L3 禁切片), 与
   原实现逐位对拍一致 (GATE 自检)。

## 待办 / 局限

- H2 的宽度敏感性: 本次无宽度约束定义下全体留存净差 ≈ 0。若需要与 B3d
  对齐检验"窄区间效应", 需在条件层按宽度分层 (c2x 候选), 本次不扩展。
- GBM 对照为首标×30 种子 (任务允许的最小覆盖); 结论均按标的聚合, 无按标的
  分层结论, 无需扩展 GBM 规模。
- H4 例外 2 格 (down +0.6pp, range +2.2pp) 未经多重比较校正; 若在条件层按
  方向状态做 1:1 检验, 需以 GATE≈50% 门禁复验。
- 触碰样本较 B3d 少 (边界触碰 + recent 剔除), 4h(3,0.5) H4-range n=210 仍
  过 MIN_N 但边缘。
