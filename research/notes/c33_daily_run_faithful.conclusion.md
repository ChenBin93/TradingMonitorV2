## H1–H3 逐条裁决

- **H1 不支持 (1/5)**: 五个传统标的日线中, 只有 ^TNX (10y 国债收益率, 1962-2026
  共 64 年) 的 N(run≥6)=403 显著超出对称硬币 95% 区间 [223,270] (L19) — 长期
  利率趋势产生真正的长 run。其余四个: SPY 105 低于硬币区间 [112,143] (L15,
  薄尾), CL=F 90、GC=F 91、EURUSD 80 全部落在硬币区间内 (L16-18)。书"日线
  run of 6 超出对称硬币"在其语境**大部分不成立**, 只有强长期趋势的 ^TNX 例外。
- **H2 不支持 (0/2)**: 加密日线 (3y) N6=14/17, 落在硬币 95% 区间 [11,23] 内
  (L23-24) — 加密日线无运行肥尾 (与 c31 的 1h/4h 薄尾一致)。
- **H3 不支持 (1/7)**: 漂移修正基准下, 只有 ^TNX 仍超出 (403 > [231,272],
  L32) — ^TNX 的肥尾超出漂移可解释部分; 其余标的在漂移 GBM 下均区间内或
  低于 (L28-34)。书硬币基准会把漂移误判为肥尾的担忧 (c18) 部分成立: 对
  SPY, 漂移 GBM 的 N6 均值 (134) 高于硬币 (128), 真实 (105) 反而更低。

## 对书 CH1/CH8"日线运行肥尾=趋势利润唯一来源"的确切回答: **仅 ^TNX 成立**

忠实复现 (日线 max 历史 + 对称硬币 + run of 6 锚点) 下, 书断言**在 5 个传统
标的中 1 个成立** (^TNX: N6=403 vs 硬币 [223,270], 且超出漂移可解释部分,
L19/L32), 4 个不成立 (SPY 薄尾, 其余持平, L15-18)。加密 (3y 日线) 不成立
(L23-24)。**结论**: "运行肥尾"不是普遍市场事实, 而是出现在具有长期趋势的
资产 (10y 利率) 上 — 这恰好是 1980s 书写作时代最明显的长期趋势; 对股票/
商品/FX/加密, 日线同向 run 不比抛硬币长。

加密日线 N6 落在硬币区间内 (0/2, L23-24), 与多数传统标的 (区间内或薄尾)

## 与 c31 的口径修正对照

| | c31 (旧口径) | c33 (书原口径) |
|---|---|---|
| 频率/历史 | 1h/4h, 3y | **日线, max 历史** (^TNX 1962-) |
| 基准 | GBM (零漂移) | **对称硬币** (书) + **漂移 GBM** (修正) |
| run 定义 | 0 断且不计, gap>2×标准间隔断 | **0 计延续**, gap>7 天断 (数据停更) |
| 统计量 | P(run≥k) 每 bar | **N(run≥k) 计数**, 主判据 k=6 |
| 结论 | 加密/传统均薄尾 | 传统仅 ^TNX 肥尾, 其余持平/薄尾; 加密持平 |

两个口径都不支持"运行肥尾普遍存在" — c31 全薄尾, c33 只有 ^TNX (长期趋势
资产) 例外。**c33 修正了 c31 的口径错位, 结论方向一致但更精细**: 肥尾确实
存在, 但只在有长期趋势的资产上, 不是书暗示的普遍市场事实。

## 设计偏离 (预注册, 非 post-hoc)

1. **gap 阈值校准 (运行前标定)**: 预注册"间隔 > 2×标准间隔断"字面实现会在
   周末 (3 天 > 2 天) 断 run, 使书锚点 "run of 6" 结构性不可达 (dev 实测
   SPY N6=0)。预注册原文"日线序列无需 gap 断裂"表明该规则只是数据停更护栏;
   实测日线间隔分布正常 1~5 天, 真停更 ≥7~18 天 → 校准阈值 gap_thresh_days=7
   (间隔 > 7 天断)。
2. **0 变化计延续** (声明, 与 c31 不同): 贴近书日线连续序列口径; 日线平 bar
   极少, 影响微小。
3. **CL=F 数据瑕疵**: 负价 (-37.63) 使 log 收益产生 NaN — 漂移 GBM 的 μ/σ
   估计用有限值掩码剔除 (布尔掩码); 真实 run 计算不受影响。
4. 硬币/漂移 GBM 基准为纯 iid (无 gap), 真实序列的停更断 run (罕见) 使
   H1/H2 为保守检验。
