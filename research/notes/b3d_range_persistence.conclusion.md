【核心结果 1 — 真实区间延续性显著成立 (用户逻辑验证 ✓)】
  触碰后"收盘在区间内部 (S.price, R.price)"的根数占比 (真实 − GBM):
    w=6 : +5.3% / +8.2% / +8.5% / +9.1%   (4 组合, 全部正)
    w=12: +4.4% / +7.8% / +7.7% / +6.9%
    w=24: +4.4% / +7.2% / +6.0% / +6.2%
  → 触碰区间边界后, 真实市场价格更倾向留在区间内部, 全部组合显著正,
    w=6 最强 (+5.3~9.1pp) — 参数无关/周期无关
  全体区间内 bar (非触碰为主) 留存: 真实 − GBM = +8.2~+12.0pp (更强)
  触碰后区间剩余存续: 真实 8.4~12.9 根 vs GBM 5.7~8.1 根 (长 1.9~5.0 根)
  → 延续性在"触碰后"条件化下依然成立, 且真实显著强于随机

【核心结果 2 — 延续性在结构维度, 不在方向维度】
  P4 趋势 × 区间内触碰反向概率 (触下沿后 P(c[t+24]>c[t]) 等):
    涨趋势: Δ -1.6% / -4.4% / -10.2% / -4.6%   (全负)
    跌趋势: Δ -2.2% / -2.6% / -2.2% / -1.5%   (全负)
  → 延续性的体现是"留在区间内" (绝对结构), 不是"涨跌方向" (相对价格)。
    "回到区间内部"≠"向某方向走" — 围墙真实且更结实, 但墙内方向无偏。
    与 B1/B2/B3/B3c 一致: 方向维度 (任何定义) 无特异性。

【度量口径修正 — 之前"留存不特异"是参照系错误】
  B3 的 M1 "留存本侧"参照位带中心线 (触下沿后 c[24] > S.price):
    混入"突破区间上方"行为 (涨破 R 也算本侧) → 真实 60.4% vs GBM 63.0%
    净差 ≈0 (错误口径)
  B3d 的 P1 参照双边界 [S.price, R.price] (真正的"区间内部"):
    真实 54.8~57.1% vs GBM 47.1~49.5% (w=6) → 净差 +5.3~+9.1pp (正确口径)
  → 用户"触碰后倾向回到区间内部"的直觉是**对的**; 之前结论的错误来自
    度量定义 (单边界/中心线参照), 不是市场。B3d 双边界实现是其正确版本。

【结论 — 逻辑与数据和解】
  1. 用户的逻辑链完整成立: 震荡延续性 (B2d 存续 15 vs 13) → 触碰后倾向
     回到区间内部: 真实 − GBM = +4.4~+9.1pp (w=6 最强) — 这是真实的
     市场规律, 不是随机游走机械性
  2. "回到区间内部"是结构/约束维度的延续性 (与 B3 位移约束、B2d 波动

  3. 数据获取方式确有问题的环节 = 度量参照系 (单边界 vs 双边界), 已修正
  4. 触碰 = 区间延续信号: 触碰后 6 根内留在区间内 真实 54.8~57.1% vs
