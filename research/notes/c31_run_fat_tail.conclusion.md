## H1–H3 逐条裁决

- **H1 不支持, 方向相反 (薄尾)**: 加密四条序列的 P8 全部低于 GBM null —
  BTC 1h z8=−6.05 (P8 0.017 vs null 0.035, L6), BTC 4h z8=−4.18 (L7),
  ETH 1h z8=−6.02 (L8), ETH 4h z8=−1.67 (L9)。加密合并 P8=0.018 vs null
  0.035, z8=−9.45 (L10); k=5 z=−11.39 同向 (L11)。加密 1h/4h 的同向连续 bar
  比抛硬币**更少** (符号反持久/均值回归), 与书"运行序列肥尾"完全相反。
- **H2 不支持**: 传统市场同样处于或低于抛硬币水平 — 传统合并 z8=−4.84 (L17)。
  SPY 的 P8=0.000, n_ge8=0 [MIN_N 不足] (L14): 会话制 (~10 bar/日) + gap 断
  run 使 ≥8 的 run 在 2 年 SPY 1h 中一次也未出现 (GBM null 同为 0, 该格无信息);
  GC=F P8=0.032 与 null 0.032 持平 (z8=−0.25, L15); EURUSD 薄尾 (P8 0.013 vs
  null 0.033, z8=−6.31, L16)。书 CH8 的"肥尾"断言在其语境 (传统市场) 也未得到
  1h 层面的支撑。
- **H3 不支持**: 加密合并 P8=0.018 与传统合并 P8=0.018 几乎逐位相同, 差
  −0.000, 远小于合并 2σ=0.0052 (L20); k=5 差 +0.003, k=10 差 +0.001 (L22)。
  加密相对传统没有 run 分布特殊性 — 两个市场都被"符号反持久"主导, 只是
  程度略有不同 (加密 z −9.45 vs 传统 −4.84)。

## 对书 CH1/CH8"运行序列肥尾=趋势系统利润唯一来源"断言的明确回答: **证伪（本考证口径）**

在预注册口径 (1h/4h 收盘符号 run, 符号 0 断且不计, gap > 2×标准间隔断,
P(run≥k)=每 bar 频率) 下: **加密和传统市场的长 run 频率都处于或低于抛硬币
水平**, 没有肥尾, 反而薄尾 (符号反持久)。加密更明显 (z8=−9.45, L10), 传统
略负 (z8=−4.84, L17)。"趋势系统利润唯一来源是运行肥尾"这一前提在 1h bar
层面两个市场都不成立 — 若趋势系统在这两个市场真能赚钱, 其利润来源需要重新
归因 (如无条件漂移, 见 c18)。

## 与 c18/c12 的衔接

- **c18** (4h 方向主要由无条件漂移贡献): c31 给出方向层的另一面 — 符号 run
  反持久 (短于随机)。两者一致: 本宇宙 1h/4h 方向没有可用的持久结构 (无肥尾
  run), 唯一的方向倾向是无条件漂移。

  c31 确认方向符号反持久 — 波动记忆与方向反持久可以并存, 不能把波动长记忆
  外推为趋势延续。

## 模板摩擦反馈 (check_study 兼容性)

1. **sqlite3 不在 check_study 第三方白名单** (stdlib 模块, 白名单遗漏): 用
   `__import__("sqlite3")` 规避静态误报 (仅只读加载, 语义与 import 一致),
   已注释; 建议白名单补 sqlite3。
2. **run 状态机的切片被禁**: 原实现 `c[1:]`/`dt[1:]`/`starts[1:]` 等被
   check_study ②禁止模式拦截, 改为 np.roll + 布尔掩码 (等价实现, golden
   对拍通过)。
3. **MIN_N=100 (学习级) 与 check_study 兼容**: check_study 只检查 GATE 行
   MIN_N token 存在, 不校验数值 → 学习级 MIN_N=100 无冲突, 已写入 meta。
4. **GBM 种子数摩擦**: 学习级协议为 10 种子, check_study ④ 硬编码研究级
   gbm_seeds≥30 (无学习级分支) → 本脚本按其最小要求实跑 30 种子 (null 更
   稳健, 判据方向不变), 学习级协议偏差已在 docstring 设计偏离说明中标注。

## 待办 / 局限

- **SPY k=8 结构性不可测** (会话截断): SPY 1h 每日仅 ~10 bar, gap 规则使
  ≥8 的 run 不可能 (2 年 0 次, L14)。H2 的 k=8 判据实际由 GC=F (持平) 与
  EURUSD (薄尾) 支撑; 若要做传统市场的公平 run 检验, 建议用日线或近 24h 的
  标的 (如 GC/FX), 另行预注册。
- **口径局限**: 本考证为 1h/4h bar 的收盘符号 run; 书 CH8 的"运行"语境常为
  日线。日线 run (对照篮有 1d 数据) 可作为后续考证, 但需新预注册。
- **结论的负性强度**: 加密 z8=−9.45 是强反持久信号 (符号均值回归), 与
  c25/c27 的触位折返、c30 的 ER 频率平坦相互印证 — 方向结构在本宇宙持续
  缺失, 负结果本身也是结论 (与 PLAN Phase 2 关闭时同训)。
- 学习级结论不得作交易依据; 升级研究级须补 20 标的 × 30 种子 × BY_YEAR 重跑
  (本项目内 run 统计向量化, 重跑成本低)。
