# 随机游走对照实验 — Hurst≈0.5 不等于无 edge (2026-08-02)

## 问题
三周期 Hurst≈0.5 (收益无长记忆) — 是否意味着市场是随机游走、策略 edge 是假的?

## 对照实验
在模拟数据上跑同样的插曲策略 (日线/4H MA 错位回调 + 沿日线方向 1:1):
| 数据 | 插曲 1:1 胜率 |
|------|----------------|
| 纯随机游走 (i.i.d. 正态) | **50.2%** (n=22273) |
| 随机游走 + GARCH 波动聚集 | 51.6% |
| 真实市场 (3年 20标的) | **54.7-57.3%** (高波动插曲 62.7%) |

## 结论
1. **Hurst≈0.5 = 收益无长记忆** (无条件), 不等于市场无结构
2. 若市场真为纯随机游走, 插曲策略应 =50.2% — 真实 57% 显著偏离 = 市场结构 (趋势延续/回调/插曲) 的真实可预测性
3. 波动聚集 (GARCH) 只解释 ~1.5pp — 真实市场有额外结构
4. 无条件随机 (Hurst=0.5) 与条件可预测 (环境选择) 不矛盾:
   交易是条件行为, 特定入场条件选中有利子集 — 类比: 轮盘独立但庄家优势来自规则
5. 模拟对照反证: 我们的 edge 是真实的, 非统计假象
