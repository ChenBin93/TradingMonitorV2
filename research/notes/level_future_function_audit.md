# 未来函数审计 — 关键位/插曲体系回测证据崩塌 (2026-08-03)

> 重大发现：**三层未来函数污染了几乎所有状态×关键位研究的回测数字**。
> 严格无未来函数修复后：贴位/顺大逆小/插曲/质量分的全部优势消失（收敛到 50%±2pp）。
> 唯一残留：**做空侧 +2-3pp**（全状态一致）。

## 三层未来函数

| 层 | 位置 | 污染 | 影响 |
|----|------|------|------|
| 1. 日线状态 | `ds.get(ts.date())` 用**当日未收盘日线** | 状态含判定窗口前 12h 走势（双重计数） | 最大：虚高 5-15pp |
| 2. 1H 极值确认 | `rolling(5, center=True)` 极值需未来 2 根确认 | "贴位"含未确认极值 | 类型 A 的 58.4% → 47.6% |
| 3. 4H 状态 | searchsorted 已收盘 | 无 | - |

level_state_*、level_target_grid、level_touch_mode、param_scan(_env)、vol_state、trendline、

## 机制解释

1. **日线状态未来函数**：D 日 12:00 采样用 D 日状态（收盘 24:00）→ 状态包含 12:00-24:00 走势，
   与判定窗口（12:00 起 24h）重叠 → "顺向"样本 = 已上涨 12h 的样本 → 继续涨概率高 → 虚高。
2. **极值确认未来函数**：is_low[i] 需 l[i+2] 确认 → 回测中"最近低点贴住"含未确认极值；
   实盘需等 2 根确认，确认时反弹已走完 → edge 消失。
3. **修复后 ≈ 随机**：与 Hurst≈0.5、HMM 方向学不到、记忆窗口（1H 方向记忆仅 2 根）完全一致——
   市场 1-2 天 horizon 方向近乎不可预测，机械规则无 edge。

## 幸存结论（需进一步验证）

1. **做空侧 +2-3pp**：全状态/全贴位定义一致（做空 50.4-52.8 vs 做多 47.7-50.4）
   → 待分年验证（是否熊市年才有 → 周期效应 vs 稳定结构）
2. **5M 反转 K +2.4pp**（4 大币）：验证记录在 STRATEGY_VALIDATION.md，脚本未找到 → 需重新验证
3. BB 反转 68%：验证脚本状态查询方式待查（signals 回测）
4. 波动状态（vol_state 62.7%）：**同样污染（ts.date()），作废待重验**

## 实盘含义

1. **回测=最差情况 = 50%**：机械规则（状态×贴位×方向）无正期望，
   **全部 alpha 在人工**（主观判断 + 及时入场 + 订单管理）
2. "及时入场"（未确认极值处入场）是回测测不到的人工能力——可能是真实 alpha 来源
3. live 系统的量化胜率标注（场景 57-61%、贴位 65-67%、质量分）**失去统计依据**
   → 建议降级为"无验证结构提示"或移除数字
4. 监控系统的价值 = 结构呈现（S/R 位置、状态、RR 计算），不是胜率预测
