## 设计偏离 (必须写明)

1. **GATE 增加真实侧无条件基线**: 原脚本 GATE 只有 GBM 30 种子 null 断言
   (探测器=同管线 null)。本次审查按 PLAN §1 L3 "存在无条件基线（真实+GBM）"
   与 c12 先例, 在 GATE 行同时报告真实 1h(2,0.3) 全部触碰 M2P50=1.544
   (n=460250) (.out:L2); 断言仍只作用于 GBM null (∈ 探测器区间, 触碰 n≥10000),
   真实侧仅作对照, 不改变任何研究结论。
2. **区间内判定用"close 到对侧位带距离"而非 B3 的"双位带间距"**: c14 的
   pair_active = 对侧位带存在且 d_opp ≤ range_atr×ATR (d_opp = close 到对侧距离;
   range_atr 为 PARAMS 常量); B3 的 active = 双侧位带存在且 (r.price − s.price)
   ≤ range_atr×ATR。前者的距离通常
   更小, 判"成对"更宽松 → 真实 区间内 n=23559 (1h(2,0.3), L7) 高于 B3 的 6817。
   该偏离只影响与 B3 绝对桶量的可比性; H3 是 c14 内部两种条件化的对照, 不受
   影响; 与 B3 的历史对照仅作形状参照 (L36, 已标注不作证据)。
3. **GBM null 构造不同**: c14 用 sim_market.gbm_matching (时间锚定真实索引, σ 由
   对数收益估计, 固定种子 0..29); B3 用 gbm_dataframe (10 种子, 种子 900+,
   无时间锚定)。故绝对 Δ 与 B3 不同 (1h(2,0.3) 区间内 -1.035 vs -0.675),
   方向与形状一致。
4. **"[t-23,t] 突破剔除"掩码在脚本内用前缀和实现** (causal_confirmed 不返回该
   掩码, 脚本内实现并注明, 与 causal 同技术; 非 searchsorted, 非自写条件化出口)
   — 已在 docstring 预注册 (脚本 L41-49), 此处不重复为结论新分层。

## 待办 / 局限

- H3 rel=0.0% 是"零差异"极值: 说明 [t-24,t-1] 泄漏区与 [t-23,t] 剔除区在本
  数据集上没有改变区间内桶的成员。成因可归为: 已 confirmed 突破的位带在确认
  窗口内很少再被触碰 (价格多保持在外侧), 或这些触碰全部落入 [t-23,t] 剔除区。
  在更长历史/更多标的上可复查该零差异是否稳健。
- 区间内桶量随周期/参数变化大: 1h(2,0.3) 真实 23559 vs 4h(3,0.5) 3630 (L7,L25);
  4h 组合样本相对小但全部 ≥ MIN_N。
- 描述层事实 (位移约束、泄漏敏感度 0) 不构成任何交易含义; 若要进入条件层
  (如 c21 区间触碰小目标), 需按 C 系列协议在 c2x 重新预注册并过全部发布门槛。
- GBM null 用首标参考 (位移分布为 ATR 归一尺度不变度量, 标的选择影响微小 —
  已在 docstring 预注册); 4h 序列较短, 单种子事件量小, 但 30 种子合计
  n 全部 ≥ MIN_N (L19-28)。
- 2023 为部分年 (8 月起始), 未纳入 BY_YEAR (与 c12 同约定)。
