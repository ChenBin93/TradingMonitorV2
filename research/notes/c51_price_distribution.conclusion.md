## H1–H4 逐条裁决

- **H1 部分**: 带触碰的**顺势** D1 53.4% 高于 GBM null 49.6% (+3.8pp, 未达
  2σ=4.8pp, L6) — 方向支持"出带=强弱势确认"; **逆势** (fade) 46.6% 低于
  null (L7); 留存率 53.6% ≈ null 53.8% (L8)。**书双用途裁决: 顺势侧优于
  逆势侧 (+6.8pp 差), 顺势相对 null 边际正但未显著** — 书的"两种用法不给
  结论"在本数据上偏向顺势, 但两者都不具统计显著性。
- **H2 支持 (强)**: 带触碰后 24h 波动释放 E1 = +14.46% vs GBM +3.25%±0.67%
  (L11) — 出带触碰伴随巨大波动释放 (+11.2pp 超 null ~17σ), 与 c15 的触碰
  释放 (+7.44pp 净) 同向且更强。波动事实扎实。
- **H3 不支持**: 窄带状态 (带宽<1y 滚动 10% 分位) 后的 24h 波动
  (0.0134) 与块 bootstrap 波动聚集 null (0.0138±0.0012) 无差异 (超额
  −0.0003, L14) — **带收窄本身在波动持续性之外不提供额外预测力** (波动
  聚集已解释大部分, 块 bootstrap 正确保留了持续性)。
- **H4 不支持**: 滚动直方图分布位 (47.8%) 与 c14 cluster_levels 关键位
  (49.6%) 的逆势触碰 D1 都落在 GBM null (47.7%±3.9%) 内 (L17) — 两套位
  均无超 null 的围墙效应 (与 c17/c23 的"关键位触碰 1:1 无优势"一致)。

## 书双用途终审

书 p.802 承认"出带=强弱势确认（顺势）或异常值回归（逆势）"两种用法不给
结论。本考证裁决: **顺势侧相对逆势侧更优 (+6.8pp), 顺势相对 null 边际正
(+3.8pp, 未显著)** — 数据不支持逆势 (fade) 用法, 顺势用法方向对但未达
统计显著。**双用途里"顺势"弱胜, 但两者都不构成超 null 的优势**。
