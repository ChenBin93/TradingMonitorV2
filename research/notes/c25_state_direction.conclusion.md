## 解读

1. **状态条件化增量 ≈ 0 — 净差是无条件漂移的镜像**: H1 主端点 ΔWR +1.83pp
   的漂移分解 (L10): 无条件层 (真实 short 无条件 51.47% vs GBM 49.70%)
   = +1.77pp, 状态增量层 (trend_up 段首格 51.28% − 真实无条件 51.47%)
   = −0.18pp。即"trend_up 状态进入"这一条件在 1:1 命中口径下不携带方向
   信息; 净差几乎全部来自真实市场无条件 short 漂移。c18/c11 的"状态段首
   E1 偏移"发现 (trend_up short 侧端点净差显著为正, 见 c18_dir_null.out) 在
   1:1 命中口径下消失。
2. **端点方向 ≠ 1:1 命中 (c23 教训实证)**: trend_down 1h E1 无方向 (c18
   +0.00pp), 但 1:1 trend_down→long 净差 −2.63pp (L13); trend_up 端点净差
   显著为正 (c18) 但 1:1 净差仅 +1.83pp。端点符号度量与"W 内先碰 ±1ATR"的命中结构
   是不同信息 (c18 端点数字见 c18_dir_null.out, 仅作先验对照)。
3. **成本 0.14% 吃掉全部 1:1 期望**: 真实 E[R] +0.0254 < cost 0.1308 →
   E_cost −0.1054 (L24)。1:1 对称策略的 ATR 单位期望仅 +0.0254 量级, 远小于成本
   (约 0.13 ATR, 因为 1h 的 ATR/price ≈ 1%) — 即使 H1 达 +3pp 下限, E[R]
   仍不足覆盖成本。门槛⑧ (成本后 > 0) 结构性不可达。
4. **H4 无梯度但方向一致为正**: 阶段三格 ΔWR 全部为正 (+1.41~+2.81pp),
   梯度 +1.40pp < 2pp (L21) — 无梯度判据通过; 但三格同为正说明该正净差
   是共享成分 (漂移), 非阶段特异性 (early/accel 略强于 late)。
5. **HOLDOUT 方向翻转**: 全样本 ΔWR +1.83pp, holdout 2026-06..08 净差
   −1.00pp (L41) — 主端点方向未保持, 门槛⑥未达。

  为 1:1 命中**; 两者口径不同 (端点符号 vs W 内先碰), 结论以 1:1 为准。
- **c23 (条件层, 触碰条件)**: c23 用触碰条件 (涨触阻空/跌触撑多), c25 用
  纯状态 (无触碰)。c25 显示状态单独无 1:1 增量 — 若 c23 有 edge, 信息源
  在触碰条件而非状态本身; 若 c23 也无 edge, 则与 c25 一致 (方向信号在
  1:1 口径均不成立)。

## 设计偏离 (必须写明)

1. 状态用 trend_states_vec 向量化复现 (c16 同款) 而非 c18 的 state_series
   逐 bar 循环 — GATE 对拍错位 0 (L2) 保证语义一致。
2. 1:1 直接测命中率 (open 出发先碰语义 + 双命中 skip + expired), 不经
   端点方向外推 (c23 教训); c18 的 E1 仅作先验对照。
3. 成本模型 0.14% of notional (taker 0.05%×2 + 滑点 1bp + funding
   0.01%×3), 每笔成本 = close[entry] × 0.14% / ATR[entry] (ATR 单位, L5)。
4. HOLDOUT 为主端点 (1h trend_up→short) 参数冻结下一次评估 (2026-06..08),
   只报方向; 月份用 df.index.month + keep 掩码对齐。
5. 4h 仅报净差 (c17/c18: 4h 效应大部分=环境漂移), 不做门槛裁决。

## 模板摩擦反馈

1. **--dev 模式**: 用 sys.argv 检查 (白名单无 argparse); dev 时 3 种子下
   WR/E1 收敛性断言需跳过 (30 种子性质, dev 只有 3), 状态对拍断言保留 —
   模板的 dev 约定未说明 GATE 断言在 dev 下的处理。
2. **gate() 先算后检** (c21 模式): 从 main 预计算的无条件基线 (双方向) +
   状态对拍断言, 避免重复计算; 模板 gate 只算单方向, 本研究双方向 + E1
   探测器。
3. **无条件基线是主要耗时**: 全 bar 入场 evaluate_forward (1h 50 标的/种子
   × 2 方向) ≈ 30M 迭代; 全量 196s 内完成, 无需 multiprocessing。
4. **状态向量化 + GATE 对拍** (c16 模式): 模板未覆盖"复现 + 对拍"自检模式
   (对拍断言是管线正确性的关键)。
5. **HOLDOUT 月份**: ctx 只给年份, 用 df.index.month + keep 掩码 (c21 模式),
   模板未覆盖。

## 待办 / 局限

- H1 ΔWR +1.83pp 统计显著 (Holm p_adj 0.000) 但幅度低于预注册 +3pp 下限,
   且状态增量层为 −0.18pp — 净差无可归属的状态信息, 不应作为后续条件层
   前提。
- H2 的 trend_down→long 净差 −2.63pp (L13) 与 c18 端点无方向 (+0.00pp)
   矛盾 — 1:1 命中与端点方向的差异值得在 c23 对照中复核 (若 c23 触碰版
   也有类似不对称, 说明路径结构信息存在但被成本吞没)。
- 成本 0.1308 ATR 远大于 1:1 期望 (+0.0254) — 任何 1:1 对称的收盘入场
   候选在 taker 成本模型下结构性不达标; 若后续考虑 limit 入场 (c21 发现
   GBM 机械填充偏置) 需单独核算 maker 成本。
- HOLDOUT 样本 n=1144 (真实) / 1367 (GBM) 较小, 方向翻转 (-1.00pp) 需更
   长尾部样本复核。
- GBM 对照首标×30 种子; 分年 GBM 侧聚合首标 30 种子 (2026 n=4689, L40)。
