# HMM vs atr_ratio 对照 — HMM 系列收官 (2026-08-02)

## 问题
HMM 波动状态是否提供 atr_ratio 之外的增量信息?

## 结果 (BTC 1H, 3年)
**混淆矩阵 (HMM行 × atr分档列)**:
| | atr低 | atr常态 | atr高 |
|---|---|---|---|
| HMM低 | 3015 | 2963 | 195 |
| HMM中 | 1218 | 12844 | 3077 |
| HMM高 | 43 | 1621 | 1213 |
完全一致率 65.2%; 条件一致率: atr低 70.5% / atr常态 73.7% / **atr高 27.0%**

**HMM 各状态 atr_ratio 中位**: 低 0.71 / 中 1.04 / 高 1.24 (高波动态不如 atr_ratio 极端)

**预测价值 (双向 1:1, 无条件)**: HMM 50.7-52.2% vs atr 49.8-51.7% — 均无区分

## 结论
1. **HMM 与 atr_ratio 一致性 65%**, 但 HMM 对"高波动"识别显著弱 (27% vs 70%+):
   atr_ratio 是瞬时的 (当前ATR/90根均值), 更灵敏; HMM 是平滑状态, 短促高波动被平滑掉
2. **预测价值两者都无差异** — 无条件下均无 edge (符合"状态无独立edge")
3. **HMM 对系统无增量**: 波动维度 atr_ratio 已覆盖且更灵敏/可解释 → HMM 不引入 live
4. 之前落地的"高波动插曲 62.7%"用的就是 atr_ratio — 自洽

## HMM 系列收官总结
- 单维/二维 HMM 均学出波动率状态 (与业界一致), 方向学不到 (有效市场)
- 业界同样: HMM 用于波动 regime/风险管理, 不用于方向预测
- 我们的 atr_ratio 是更实用 (简单/可解释/灵敏) 的波动状态工具
- 方向识别靠环境结构 (场景引擎) — 路线确认
