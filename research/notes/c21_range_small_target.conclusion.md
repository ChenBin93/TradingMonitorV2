## 解读

1. **H1 否定但胜率结构稳健**: 触下沿 limit 小目标在 4 组合全部呈现 ΔWR
   +4.45~+6.74pp (全超 +3pp 下限, L8-11), 分年 11/12 正、唯一负年差幅在
   1pp 内 (L150)。但 ATR 单位净期望仅 1/4 组合达标: dev +0.0400 (L8),
   4h +0.0393/+0.0495 (L10-11)。根因: GBM 同管线机械偏置本身携带
   +0.0005~+0.0636 ATR 正期望 (GBM E 列, L8-11) — 触碰条件化 + limit
   填充位置优势在无信息市场上已产生约 +0.06 ATR 的机械正期望 (c15 教训
   的放大版, 来源是填充位置而非仅波动释放), 净差扣除后剩余幅度不足
   +0.05R。
2. **H2 否定 (追价劣化结构成立, 严格伪影不成立)**: 收盘入场版净差
   +1.33~+2.41pp, 超出 ±1pp 判据 — 收盘入场并非零净差, 真实均值回归
   信号在收盘版上也有小幅体现。但量级约为 limit 版的 1/3~1/2 (ΔWR
   +1.3~2.4 vs +4.5~6.7, L48-72 vs L8-11) — "追价劣化"结构成立, B4e
   的"净差=追价伪影"严格版本 (净差≈0) 不成立。
3. **H5 否定 (c24 前置过滤不成立)**: 低波动子集在真实侧增量全部为负
   (−1.00~−2.94pp, L145-148), 即低波动触碰的胜率反而更低; 4h(3,0.5)
   GBM 增量 +2.18pp 为正 (L148) — "低波动增强"前提被否定。
4. **选参结构**: dev 集按 ΔE 最大化选中 (0.3,1.0,6) (宽止损 S=1.0,
   L116), 而非预注册 (0.3,0.7,6); 选中格验证组合 ΔE: 1h(3,0.5) +0.0714
   (L24)、4h(2,0.3) +0.0620 (L32) 达标, 4h(3,0.5) +0.0445 (L40) 未达 —
   跨组合一致性仅 2/3。

## 设计偏离 (必须写明)

1. **E[R] 单位 = ATR**: 每笔成交交易 R ∈ {+T (win), −S (loss), 0
   (expired/skip)}, E[R] = (T×n_win − S×n_loss)/n_filled; unfilled 不计;
   "0.05R" = 0.05 ATR。B4e 的"期望"为 ±1 单位, 数值不可直接对照。
2. **成本模型**: maker 0.02%×2 + 滑点 0.5bp = 0.045% of notional (L138),
   每笔成交成本 = entry_px × 0.045% / ATR[t] (ATR 单位); 简化假设 maker 双边
   (stop 触发市价单实为 taker, 滑点 0.5bp 近似吸收)。
3. **成交搜索无时限** (simulate_limit_entries 官方语义, 至数据末尾);
   判定窗口 W 自成交 bar 下一根起算; 事件 tail 统一 t < n − 12。
4. **选参剔除 HOLDOUT 窗口** (2026-06..08 事件不计入 dev 选优, 防污染);
   HOLDOUT 用冻结参数在 dev 组合 holdout 窗口一次评估。
5. GBM 对照首标×30 种子同管线; 分年 GBM 侧聚合首标 30 种子。

## 模板摩擦反馈

1. **模板 gate() 为单管线自检**: 本研究改为"先算开发组合网格 → 从网格断言
   (GBM 主端点 WR/成交率/close 版 WR) → 再算其余 3 组合", 消除 gate 与主
   管线的重复聚类 (~18 min 节省), 模板可吸收"先算后检"模式。
2. **simulate_limit_entries per-event 数组** (entry_px/target/stop) 开箱
   即用, 无摩擦。
3. **多度量 × 多参数格**: 模板 run_by_year/write_out 单度量假设需重写为
   网格化聚合; pool_combo "一次 run_symbol, 多格复用" (cluster 是主耗时)
   为事件式模板的通用性能模式。
4. **Holm 校正**: math.erf 实现单侧 z 检验 + step-down Holm (running 从 0
   起, 初版 running=1.0 导致 p_adj 全 1 的 bug 已在运行前修复), 模板无先例。
5. **HOLDOUT 需要月份**: ctx 只携带年份, 用 df.index.month + keep 布尔掩码
   对齐 (无切片), 模板未覆盖月份口径。

## 待办 / 局限

- ΔWR 稳健但 ΔE 未达 +0.05R 门槛: GBM 机械填充偏置 (E +0.0005~+0.0636)
  的构成 (填充位置 vs 波动释放) 未分解 — 若后续要复用本结构, 需单独研究
  该偏置的机制。
- 4h(3,0.5) 组合 ΔE 最弱 (+0.0393~+0.0495, L10-11/L40): min_touch=3,
  tol=0.5 的宽位带使填充位置优势更机械。
- 分年 GBM 2026 样本偏小 (最小 n=211, L150), 2026 年 GBM 侧精度有限。
- H5 低波动过滤为 c24 前置, 已否定; c24 需另寻过滤维度。
- HOLDOUT 只报方向 (n=327 real / 115 GBM), 不做幅度断言。
