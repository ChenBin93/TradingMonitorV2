## H1–H3 逐条裁决

- **H1 判据不成立, 但描述层有真实可见的周内结构**: 真实 P[周二跌|周一涨] =
  58.9% (L6) — 高于置换 null mean (51.9%), 但**未超置换 95% 区间** [32.9%,
  69.5%] (置换逐次 n 波动大, 区间很宽)。分周内边际 P(up) 很醒目: 周一 57.7%、
  周二 42.6%、周四 42.0% (n=312~314/天, L7) — BTC 与 ETH 两侧几乎逐位一致
  (周一均 57.7%, 周二 43.6%/41.7%)。**裁决**: 按预注册判据不显著, 但描述层
  显示加密确有"周一涨、周二/周四偏弱"的周内形态 — 与书图 15.14 X/O 同向;
  只是置换 null 太宽无法证实。
- **H2 不支持 (pilot 降级)**: OKX rubik ratio API 可得 (~180 日 1D, 2026-02-15..
  2026-08-13), 但极端分位 (上下 5%) 每桶 n=9-10 — 远低于 MIN_N, 无法下结论;
  连续性 Spearman 全样本 (n=167): BTC +0.026、ETH −0.004, GBM null 0.005±0.064
  (L10-12) — 真实与 null 无差, **ratio 对次日方向无预测信息** (呼应 c49 H4
  funding 无调节)。触碰折返 n=3/0 (L10-11) — 窗口太短, 退化, 不采信。
- **H3 强烈不支持书 CH16**: 无成本 (0bp) 永远在场 5m N-bar 突破**全部为负**:
  BTC N=10/20/50 = −3.12/−1.56/−1.21, ETH −1.62/−0.94/−0.43 (L16-27); GBM
  null 0.12±0.72 ~ −0.17±1.25 — 真实显著低于 null (无成本即被 whipsaw 磨损,
  反持久 c31 在 5m 更强)。加 taker 成本后更负 (BTC N=10 2.5bp = −15.87)。
  书 CH16 "无成本所有突破幅度全盈利、20 年后依然" **在加密 5m 上完全不复现** —
  连无成本都不盈利, 呼应 c21/c23/c25 (成本吃光) 且更早失效。
