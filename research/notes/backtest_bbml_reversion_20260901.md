# BBML Reversion 策略 — 独立回测验证 (2026-09-01)

> 来源: bb_ml_reversion/ (对方推送的策略包)
> 数据: data/backtest.db BTC 5M (2023-08 ~ 2026-08)
> 方法: 用冻结模型 (models_btc.json, BTC 2023-2024 训练) 跑 2025+ 样本外

**几乎完全复现** (微小差异: 本库数据 2023-08 起 vs README 2023-01, 冻结模型不受影响)。

## GBM 对照 (随机游走同管线, 4.5个月窗口 2026-03~08)

| 项 | 值 |
|---|---|
| 真实 | 202 笔, +28.57 bp/笔 |
| GBM 平均 (3种子) | +24.17 bp/笔 |
| **真实优势** | **+4.41 bp/笔** |

## 核心结论 (诚实)

1. **README 数字可复现**: 冻结模型样本外 BTC 表现与声称一致 (+31.2bp/81.3%)。
2. **但结构优势薄**: 深偏离回归的机械结构在随机游走也赚 +24bp (GBM),
   真实市场 alpha 仅 **+4.4bp/笔** — 约等于 4bp 成本的 1 倍。
3. **与仓库 C 系列结论一致**: 均值回归结构收益真实但薄, 成本敏感。
   README 自己也承认 "未含 GBM 零假设对照 (仓库纪律要求)"。
4. **实盘含义**: paper 模拟盘可跑 (无资金风险); 真实上线需关注:
   - 成本/滑点 (入场按 close, 出场按 mid 触及, 实盘有偏差)
   - 超时单尾部 (-500~-600bp, 无止损)
   - 极端行情执行假设

## 备注

- 策略代码全量回放慢 (16万根 ~90s), 模拟盘需增量式引擎
- 入场价 = 信号 bar close (收盘确认), 出场 = high/low 触及 mid — 模拟盘同口径
