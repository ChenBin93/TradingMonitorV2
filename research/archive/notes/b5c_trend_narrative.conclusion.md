B5c 趋势叙事三环节检验 — 结论 (2026-08-04, 无未来函数, 1h 基准参数, 30 GBM 种子)
═══════════════════════════════════════════════════════════════════════

用户叙事模型: ①趋势早期突破关键位启动 → ②运行中触位折返 (短期回撤) →
③再次回到趋势方向。

【H1 突破启动 — 不成立 (±12 根)】
  段起点 ±12 根内 confirmed 密度比: 真实 1.00 vs GBM 1.00 (修正排序 bug 后;
  此前 3.84/-6.50 是 all_conf 无序时 searchsorted 的错误结果)
  → 确认突破事件在趋势段起点处无聚集。注意: A2 状态判定 (ADX+slope)
    滞后于实际价格突破, 段起点可能落后突破 10~20 根 — ±48 窗口待验
    (密度比 1.00 精确值也提示滞后假设需更大窗口)

【H3 回撤恢复 — 不成立 (96 根内无恢复)】
  D1 沿趋势方向概率净差 (真实−GBM) 窗口梯度:
    W=6 : -2.0% / -2.1% / -4.3% / -4.3%
    W=12: -2.0% / -2.3% / -3.7% / -3.7%
    W=24: -3.9% / -4.3% / -2.7% / -3.1%
    W=48: -2.2% / -2.0% / -2.8% / -3.2%
    W=96: -3.1% / -2.9% / -2.3% / -2.4%
  → 全部窗口负, 无任何恢复迹象 — 触碰关键位后的逆势倾向持续至少
    96 根 (4 天), 不是短期回撤。"折返后恢复趋势"不成立

【H4 角色转换 — 刚破/未破分化是几何机械性】
  真实: up_刚破_resistance 51.7% vs up_未破_resistance 41.2%
        dn_未破_resistance 63.6% vs dn_刚破_resistance 46.2%
  GBM 同样分化 (58.1 vs 44.6 等) — 刚破位 (价格已在其外) 触碰后沿突破
  方向继续、未破位触碰后折返 = 几何必然 (位带中心参照类偏置), 两边同有
  对照后 (真实−GBM): 全部 -0.6%~-10.0% (全负) — 逆势效应在所有角色
  类型中都存在, 角色转换不提供额外信息

【结论 — 叙事模型不完全成立】
  ①突破启动 ✗ (±12 根无聚集; 滞后待 ±48 验证)
  ②触位折返 ✓ (B5/B5b: 逆势 2~4pp, 独立真实效应)
  ③恢复趋势 ✗ (96 根内不恢复)
  → 趋势中关键位的"逆势折返"是持续效应 (≥4 天), 不是短暂回撤;
    量级 2~4pp (端点概率 46~48% vs 随机 50%)
  → B5/B5b 结论稳定: 趋势关键位 = 弱逆势拒绝 (2~4pp, 持续), 方向偏好
    弱; "趋势动能足更易突破"的常识与数据差异 = 触碰关键位确实打断
    趋势 (4 天尺度), 但量级小

【方法修正记录】
  H1 的 all_conf 跨位带拼接后必须 np.sort (逐位带 confirmed 有序但
  位带间无序, searchsorted 需全局有序) — 原始 3.84/-6.50 是假象
