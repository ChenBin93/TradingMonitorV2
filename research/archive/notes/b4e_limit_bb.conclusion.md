B4e limit 入场 + 布林带 — 结论 (2026-08-04, 无未来函数, 1h 基准参数, 30 GBM 种子)
═══════════════════════════════════════════════════════════════════════

动机 (用户): ①高空低多的关键是在尽可能高/低的点下单 — B4 收盘追价入场
极差 (触下沿收盘比极值高 ~0.5 ATR) → 改 limit 挂单; ②均值回归可结合
布林带 (标准 20,2) 优化。多空一起测, 挂单价 = 位带中心。

【A limit 入场 — 执行改善巨大 (用户观点验证)】
  limit buy 挂 S.price / sell 挂 R.price, 成交价 = 位带中心, 目标 0.3×ATR
  止损 0.7~1.0×ATR, W=6, open 出发判定, 成交率 61~64% (真实 vs GBM
  67~68% — 真实插针穿透中心率略低)
  触下沿做多 (S=0.7): 真实 胜率 80.6% 期望 +0.611R
                     GBM   80.8%      +0.616R
  触下沿做多 (S=1.0): 真实 86.3% +0.719R | GBM 86.8% +0.735R
  vs B4 收盘入场: 真实 67.8% +0.355R → limit 入场绝对水平 +12.8pp 胜率
  /+0.26R 期望 — "尽可能低的点下单"完全正确, 执行改善显著

【转折 — 市场效应 (真实−GBM) 在 limit 入场下消失】
  触下沿: Δ胜率 -0.1%~-0.4%, Δ期望 -0.005~-0.016R (≈0)
  触上沿: Δ胜率 -3.6%~-4.0% (负, 受 GBM 空头路径偏置污染)
  分年: support 2023 +1.1% / 2024 +1.1% / 2025 -3.4% — 正负交替不稳定
  → B4 的 +3.5pp 净差是"收盘追价入场"特有的 (真实收盘插针收回特征 ×
    追价交互), 换 limit 入场后无市场效应证据。GBM 上 limit 同样暴涨
    (80.8%) = 执行结构优势 (极值区出发 + 目标近), 不是市场 edge。

【B 布林带分层 — 无法验证 (样本不足)】
  分层: 触下沿时 close 相对布林带 (<下轨=极值 / 下轨~中轨=中间 / >中轨
  =回收) + squeeze (BB 宽度分位)
  GBM 上"极值层"样本极端稀少 (区间内触下沿时 close 几乎总在中轨上方:
  GBM 极值层 n=4~38) — 分层对比达不到 MIN_N, 布林带增量本轮无结论

【空头侧 — GBM 基线偏置依旧】
  limit 做空 (触上沿): 真实 16.9% vs GBM 20.9% — 空头 GBM 基线 (区间内
  触碰向上路径选择) 使空头净差不可信; 绝对水平也低 (做空 = 逆插针)

【结论】
  1. 执行层面: limit 挂关键位 (中心) 是正确做法 — 绝对胜率/期望暴涨
     (80.6%/+0.61R vs 收盘 67.8%/+0.36R), 用户"尽可能低的点下单"验证 ✓
  2. 市场层面: limit 入场下真实−GBM 无净差 — B4 的收盘入场净差不可
     直接迁移; 真实可交易预期 = limit 绝对水平 (高) 但市场 edge 证据
     不足; 分年不稳
  3. 布林带增量: 未验证 (GBM 极值层样本不足) — 需补 GBM 种子或放宽
     分层 (全体触碰分层) 后重测
  4. 成本: limit = maker 费率 (~0.02%) + 无追价滑点 — B4 的成本警告在
     limit 入场下大幅缓解 (执行成本 ~0.1R 级别 vs 收盘 taker 0.3~0.5R)

【待办】
  1. 布林带分层补样本: GBM 种子 30→90 或改用全体触碰 (非区间内限定)
     分层 — 回答布林带是否正交增强
  2. 空头 GBM 基线修复 (路径选择偏置) — 空头侧结论前置
  3. B4 vs B4e 净差差异的机制理解: 收盘追价入场的净差来源 (真实插针
     收回特征) — 决定哪个是真实可交易形态
  4. 成本核算 (maker 费率模型) — 落地前置
